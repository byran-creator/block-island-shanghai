# 脚步、自然音与手机长按（2026-10-25）

原脚步仅在 y=25–30 时播放低音量三角波，容易被配乐掩盖，也未接入落地状态。本轮改为原创鞋跟与鞋底噪声叠加的短 PCM，单个 16kHz / 0.15 秒单声道缓冲（9,600 字节浮点），材质与左右脚改变播放速度。实际地面移动距离驱动节拍，飞行、滑翔、游泳、乘车不触发；按物理移动而非船体携带位移记步。高层室内和地铁步行也适用。车声运行增益 .014→.019、怠速 .003→.004，原24米平方衰减和左右声道保持。

部分NPC补近距离脚步：沿用固定人物列表，每0.2秒只做平面距离/高度及资格判断，仅保留六米内人物的短运动记录；每次采样最多一声、最多四个短音源重叠，远人/静止者/列车乘客不发声。暂停清空近人记录，停止短音源；无独立计时器。不是为全城每人创建持续音源。

园林改用Sadiquecat的CC0公园鸟鸣实录（法国Albi，非豫园实地采样），替换合成哨音和园内合成铃声，保留原创配乐。仅进入内园且声音开启后请求本游戏托管录音，不接第三方音频服务；18秒、16kHz单声道PCM16，磁盘576,044字节，解码浮点1,152,000字节，最多一个缓冲和一个循环音源。夜晚/雨天变轻，离园淡出后停止，暂停/静音/销毁即停，未完成请求不得在离园或销毁后自行播放。共用有界PCM读取器，雨声接口与数据完全保留；江水音色/增益未修改。来源、许可证和离线处理记在game/audio-credits.txt。

手机长按：仅触屏游戏按钮/摇杆/快捷栏/画布禁选字和WebKit callout；document委托拦截相关contextmenu/selectstart，不吞pointerdown/click或滚动。input/textarea/select/contenteditable保留复制粘贴及原生编辑菜单；照片导出链接保留原生操作。监听器由文档生命周期拥有，helper提供释放接口。未修改画质、人物数量、视距或存档格式。

验收记录见本轮检查点；桌面浏览器的触屏CSS/事件测试不能等同iOS/微信原生长按菜单实测，不宣称手机FPS或加载提速。新增录音不在首入城市预载，功能测试与构建检查负责资源路径/生命周期，不以主观听感代替实机试听。

验证：新增脚步/鸟鸣与长按两项、雨声兼容、语音与手机输入定向检查通过；58项test:release通过。桌面真实OfflineAudioContext验证脚步峰值0.13258、鸟鸣正常解码与输出、内园前零请求/入园一次请求；菜单事件被拦截、点击与输入保留，console无警告/错误。该峰值是数字信号测试，不是手机扬声器响度或实机听感；WebKit callout不受桌面Chromium支持，需iOS/微信复测。
