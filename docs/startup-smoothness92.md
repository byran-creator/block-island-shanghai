# 默认地图加载及人群计算 · 2026-10-23

基线 main `6f3759b`。手机默认1.25倍率、MSAA及30帧目标保持；没有减少地标、人物、几何、贴图或视距。玩家存档6、地图11、基础缓存revision84保持。

## 默认地图准备

发布构建使用当前原生成器生成默认地图，将体素的连续段压成变长整数，再与surface一起gzip，当前资产202,936字节。地图体素56,070,144字节及surface的SHA与原版分别相同：`22b9d26d0b9806b35424081da33b22df925f64ea51dff88a11892c08b48a6128`、`995465d1bbe3c03b6c5bd6d01ad3a636d8076dfe0b0c155bbf6304347d72b88a`。

入口HTML提前请求内容哈希资产，浏览器异步解压并验证压缩/展开数据的SHA、版本、尺寸及边界，然后还原原始地图和独立的建造对照数据。无需额外启动一次城市生成Worker，避免重复解析生成器模块。解码只发生在进入游戏之前，正常运行路径不新增工作。失败或不支持相关API时仍用原Worker生成；此时不再重复请求快照。人工强制重建绕过快照。原开发源码预览仍使用生成器，完整快路径由发布构建注入。

IndexedDB继续只保存默认地图，与个人建造/背包/任务存档分离；附带可复用的对照段，避免再次全图扫描。额外用当前默认地图的构建哈希核对缓存，旧缓存或生成器发生变化时重新取得默认地图，随后照常叠加玩家编辑。构建哈希不依赖普通UI小修，地图没变就不强制重做默认缓存。

Sites原网址也使用单个内容哈希前端入口，减少模块请求；保留原资源路由和云存档方式，GitHub Pages仍使用浏览器存档。两个网址的存档没有合并或互相覆盖。内容哈希入口和Worker不再二次改写，以保持文件名与最终字节对应。Sites仅对这些内容哈希资源使用长期静态缓存，HTML和无哈希模块继续每次核对版本，玩家存档接口仍为no-store。

## 人群更新

只在至少64名活动行人、128个邻居的大群中使用4格保守邻近索引；小群沿用原扫描。每步重建，实际移动后更新位置；完整距离、楼层、显隐、待出生、让路及脱困谓词保持。小群索引和另一种AABB候选在基准中更慢，未采用。2,700帧逐项轨迹与91原模块一致，覆盖阈值切换、外部行人变化、车辆、新障碍、相互阻挡、停等和脱困。

Node中含建索引成本的360步三轮样本，大群更新中位约减少9%–13%，不代表手机整体FPS提升同等比例。渲染矩阵缓存、实例重组、LOD或清晰度下降均未采用。

## 完整加载实测及边界

本机WebGL、844×390视口、真实画布1055×487、MSAA开启，固定同一随机种子、静音、禁存档、强制默认地图缓存未命中；原版和最终候选独立加载并关闭前一个页面。完整进入按钮就绪约12,326→9,574ms（约减少22%），其中模块开始后的构造阶段8,360→5,647ms。地图及建造对照数据就绪约2,987→91ms。绘制调用1,345、三角形820,434、已加载160块及待处理128块均一致，无控制台错误。
