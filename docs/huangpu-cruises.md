# 浦江观光游轮

保留原3艘小艇，新增2艘约19m长、5.6m宽的原创三层观光船：浦江明珠、云帆华彩。透明观景舱、木甲板、桌椅、救生圈、驾驶台、顶层遮阳篷、两段实体楼梯与真实楼板开口。冰蓝金色/紫金色勾边、暖色窗面、甲板珠灯、灯串与发光船名夜间开启。两艘船共用512×128木纹/装饰纹理，不复制照片或商业标识；静态细节按材质合并，无新增实时点光源、阴影、反射或粒子。

## 登船与安全

海关钟楼附近外滩临江观光码头（游戏压缩位置，不冒充真实码头精确复刻），高平台26m、缓坡下降至23.32m低平台、停船期间伸出登船栈桥。玩家可以实际步行进舱、走楼梯、航行中自由活动；V候船登船/靠岸下船提供便捷入口。行驶时侧门关闭，楼顶有护栏；船舱玻璃具有碰撞。玩家站在登船栈桥上会暂缓离泊，避免撤桥落水。暂停世界时不推进航程。

190s服务循环含30s停靠（有登船者时短暂延长），两船错开95s。航线在江面38–118m附近往返成环，回原码头；完整船体避开岸线、旧小艇、南侧轮渡和桥区。2名真实游客连续走栈桥登船、随船游览并下船，通道串行放行，回程乘客先下后上；不瞬移成装饰人像。共享NPC系统可感知游客世界坐标。

boat-support新增可选倾斜平面、楼板开口、门/墙和活动状态，原小艇/轮渡缺省行为不变。船上和低码头存档时保存岸上安全点，继续保留save6/map11和玩家所有建造/剧情记录；不保存瞬时船班，不修改底图缓存。
