# 豫园与10号线 · 2026-10-12

## 游览路线

南京路石碑附近的南向步行支路通往豫园北门；地铁豫园站在湖心亭西北侧，两处地面口分别连北门与西门。M 可传送到景区或地铁入口。地理关系按现有城市比例压缩，并非道路、出口编号或楼层高度的1:1复刻。

2号线到南京东路 → 上扶梯到B1付费区 → 紫色导向换乘通道 → 10号线站台。换乘不出闸、不重新安检。10号线体验区间为南京东路—豫园：南行「虹桥火车站 / 航中路方向」，北行「基隆路方向」。真实相邻站显示天潼路—南京东路—豫园—老西门—一大会址·新天地，未开放站灰色显示。南京东路10号线站台标识B3，世界高度沿用压缩地下空间；真实2号线B2/10号线B3层高未等比例模拟。

从地面进任一站，须扶梯下B1 → V放包安检3秒 → 旁边闸机V刷票后走过 → 下扶梯到站台。出站必须先上B1、刷出站闸机，再上地面。出闸清除两线共同票权；重新进站重新安检。无需V也可在开门后走入车厢，WASD车内移动，F坐空座/起身，走出开放车门下车；V保留辅助方式。10号线使用六节浅紫银灰10A01风格列车、圆头灯、双向路图、全高站台屏蔽门；两方向到站相差5秒，循环60秒、停站12秒、区间13秒。语音沿用现有普通话/英语及入离站声音设置，不声称新的实地录音。

## 景物与互动

九曲桥有九次转折、实体桥面与避开转角的护栏，通向双层湖心亭。池中花岛、两处低喷泉、朱红柱临水长廊、柳树、竹木和草地花床；夜间金色曲檐线、木格窗灯与红灯笼自动点亮。主要静态物件按材质合批，96粒喷泉水滴复用实例变换，不逐帧创建物体，兼容画质也显示实例。

南侧南翔小笼/江南手作、北侧湖畔茶坊设可进入的玻璃木窗店面、室内地砖、天花灯、货柜、笼屉与小笼折纹、糖豆包装、茶壶杯具、丝绸折扇和卷轴。中央门厅/柜台通道保留净空；V购买后相应展示组减少一份。小笼12份、糖豆8份、手作6份、茶具6份；每次购买间隔20秒，库存、纪念品、茶具与互动进度随玩家存档保存。Z食用、O查看收藏。没有生成真实商户交易、收费、售票或完整商城。

湖心亭V品茶恢复少量状态；灯谜向导三题须答对才能完成；I可追踪10号线实际到站、品茶、灯谜并领取一次奖励，传送不能代替乘车。8位游客按独立配速/出发相位沿南京路—豫园分开的往返路线上走，圆弧掉头；仍遵守实体障碍与车流避让。

## 工程边界与验收

新增10号线参数化复用原2号线服务、门机、座位和安检/闸机规则，原默认接口/旧存档兼容。地图修订11与既有地标保持；基础世界缓存升级为yuyuan-line10-2026-10-12-v21，首次重新生成基础城市，玩家存档独立保留。选择性让位的是生成的填充楼，其中一间南京路南侧填充商厦让位给10号线入口；其余商铺的品牌、商品与商贩编号保持稳定，不清理玩家存档文件。

测试检查四个新入口全程实体碰撞、封闭未付费边界、安检/进出闸/重新安检、跨线票权、付费换乘门洞/通道、真实方向、列车门与底板、实际到站事件、车内移动/空座；景区步道/九折桥/店门支撑与净空、商品减少/存档、灯谜去重、喷泉范围、昼夜灯组和8位游客10分钟持续进展。兼容渲染的实例变换有独立回归。浏览器仅使用静音、禁存档的本地验收页看日夜景、店内、换乘、入口与站台；该入口不进入生产包。

已知遗留项：全套 npm test 的 traffic-scene.test.mjs 和 pedestrian-traffic.test.mjs 在模拟12分钟后有北外滩车流停滞。对已发布v50干净源码运行同一测试，也出现相同车辆位置与长时间路口等待（分别在recent-progress及永久等待断言失败）；本批未改交通控制逻辑，按用户要求保留为后续车道/车流优化项，不声称全套回归通过。
