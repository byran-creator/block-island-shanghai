# 登录背景与点击启声（113 / 114）

113把主程序推迟到点击后加载，并以SVG剪影代替原背景。用户要求保留原有动态城市登录画面，114撤销这项视觉替换和欢迎页专属布局。

页面自动加载同一内容哈希主程序，准备原有真实城市背景与原菜单。没有输入时只准备背景，不激活加载音乐、不自动读取玩家存档进入。删除替代SVG及覆盖层，不改城市镜头、建筑、光照、渲染清晰度或游戏内画面。

“开始旅程”在准备期间也可点击：真实click捕获阶段同步启动同站《上海滩》片段，创建/恢复页面共享WebAudio上下文；记录进入意图，就绪后调用原按钮的存档继续入口。若等背景就绪后才点击，按原入口直接继续。原未读公告仍需确认；存档失败保留原重试，不清除缓存、个人建造或旧进度。

播放器尊重静音设置、前后台暂停及进入后的释放，音乐错误不阻断城市。不能据脚本执行或音频请求认定真实手机已经出声。自动准备城市也不等于用户手势启声。

独立经典启动脚本仍提供下载/求值错误、30秒初始下载提示、迟到进度恢复及手动重试。普通访问和专用QA页都自动准备背景；只有明确的开始点击才自动衔接进入。就绪释放观察器、计时器和错误监听。

相关回归覆盖自动准备但不播放/进入、加载中点击与就绪后原入口、重复点击、公告确认、迟到进度和错误恢复。发布检查与独立静音隔离页面验证不等于微信真机扬声器验收。
