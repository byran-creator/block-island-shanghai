# 地图传送、通勤与陆家嘴灯光秀

本次只在本地更新，地图坐标修订仍为 11。更新前本地存档备份为 `.local-data/backups/saves-before-commuting.json`。

- **M 打开地图**：点击青色景点圆点，或地图下方的景点按钮。外滩、北外滩、明珠、三件套、南京路、和平饭店、白玉兰和停机坪等 16 个落点检查地面支撑与碰撞。跑酷期间不能传送。
- **Shift 跑步，CapsLock 切换持续跑步**：步行 4.5、跑步 8.5 格/秒；跑酷保持原来的 7 格/秒上限。水中与滑翔时，Shift 仍用于下降。触屏有跑步按钮。
- **V 上下车**：西岸九江路／福州路附近滨江步道与陆家嘴绿地附近有可骑自行车；九江路、广东路滨江步道及浦东商业街有停放汽车。自行车、汽车 W/S 前进／刹车倒车，A/D 转向，松开前进键后减速。驾驶使用第三人称跟随视角，鼠标可环顾；车辆不能穿墙或驶入无支撑江面。
- **公交乘客**：公交停站时靠近车门按 V。按原车道运行，停站、等红灯，V 在安全位置下车；乘客不会再被当作车前行人而使公交停住。
- **白玉兰直升机**：地图传送停机坪，走近机身按 V。W/S 前后，A/D 偏航，空格上升、Shift 下降；降落到地面或停机坪后按 V 离开。桨叶在驾驶时旋转，机身有碰撞检查。
- **K 灯光秀**：42 秒无人机／烟花表演采用三处江面发射点，低空扇形与高空花球、圆环、垂柳交错。18 处聚光灯每处三束扇形扫光，约 1.2 秒节拍交错闪亮；楼群灯带、地标与广告屏统一金色／冰蓝／玫红／金色配色。结束后关闭聚光灯，烟花余尾自然消失。菜单直达的观赏点避开屋檐与路灯。详细实景依据见 [烟花与桥梁记录](harbour-show-and-bridge.md)。这是原创游戏编排。

驾驶时保存会记录附近安全下车位置；直升机悬空时记录起飞点。读档恢复步行，载具仍从初始停车位置生成，暂不持久保存车辆位置。地图传送与回出生点会退出交通状态，避免车辆或轮渡下一帧覆盖传送位置。原始存档文件未被测试页覆盖。

碰车后按 **S** 刹停并倒车，已有重叠允许沿减少重叠或离开对方中心的方向脱困，继续挤向对方仍被拦住；自行车也可从静止后退。直升机必须落地后下机，退出点检查脚下支撑、世界障碍、交通工具和机尾；退出后清除驾驶按键、恢复步行，并朝远离载具的方向看。靠墙导致直升机跟随镜头缩进机舱时，镜头选择无遮挡的上方位置。

NPC 对话改为底部渐变面板，镜头朝向谈话人物，隐藏物品栏等 HUD，右侧显示回答选项。交警问路、商贩购买入口与 Esc 退出仍沿用原有功能。

东方明珠改为下球半径 5、上球 4.5 格，上下球直径比为 10:9，平台与霓虹圈一起缩窄，保留原有电梯落点和总高度。旧存档若停在缩窄前的平台外缘，读取时移至同层附近有支撑的位置，飞行和滑翔存档保持原状态。比例依据用户的双侧实景图，以及[中国网的清洗作业照片和球体尺寸报道](https://www.china.com.cn/newphoto/2013-10/29/content_30430734.htm)。模型仍按游戏比例压缩。

验证：实际地图按钮传送到南京路；浏览器检查骑车、公交乘坐、直升机起飞和悬空退出提示；自动测试覆盖 16 个落点、地图命中、车辆扫掠碰撞、车后相机遮挡、骑车位移、公交载客离站、安全下车／存档、直升机退出保护、明珠电梯落点与聚光灯交错／关闭。临时检查页禁用保存，检查结束后移除。
