# 性能与稳定性维护 · 2026-10-16

本轮保留既有画面、贴图、游客、灯光、道路和存档格式。只处理地形网格临时内存、人车碰撞的无效计算，以及用户追加的普通NPC对话结束操作。没有新增玩家小版本公告。

## 地形网格

原实现将全部顶点、法线、UV、颜色和索引先装入普通JavaScript数字数组，再复制成显卡需要的类型数组，造成生成时的内存峰值和回收压力。现分两阶段：先用每个方块一个字节记录六个面的可见性，再一次性分配最终数组直接写入。两阶段均按列让出执行权，保留原队列的编辑作废、旅行取消、3ms处理预算和每帧最多一个完成上传。安装`BufferAttribute`直接使用最终数组，不再复制。

完整基础地图1521分块对照，7,229,632顶点、1,807,408面和339,792,704字节最终数据完全一致。位置、法线、颜色、UV、索引的SHA-256均为`6a43d7c97270ff92cd41c004edabbc2bed39a69d4240a5d653f082bc88b6441d`。不是减少面数、贴图精度或视距。

三轮交替串行的独立Node进程压力测试，中位数如下：

| 指标 | 原实现 | 本轮实现 |
| --- | ---: | ---: |
| 网格生成耗时 | 5087.62ms | 3236.64ms |
| 进程峰值RSS | 601148KiB | 475228KiB |

此工作负载耗时约减少36.4%，峰值RSS约减少20.9%。它遍历完整地图、保留最终数组，包含世界和运行时开销；不能解释为整个浏览器常驻内存降低21%，也不是FPS。早先单次样本有并行测试干扰，已保留为`terrain60-after-concurrent.json`，不计入最终配对结果。最终三轮原始数据在`.local-data/qa/terrain60-paired.json`。

## 人车碰撞

原碰撞对远处的人车仍执行旋转坐标、三角函数和精细相交判定。新增保守外包方形预筛选：旋转矩形半宽、半长之和包住任意朝向，行人加原`.36m`半径，车辆加对方尺寸与原安全余量；只跳过不可能接触的远处对象。近处仍执行原窄相位计算，不改让行、信号、车道、行人转向或穿模规则。

40,000组固定种子的近处、远处、旋转、行人、车辆、高差、隐藏和自身情况，与正式65d92aa的冻结参考计算得到逐值完全相同的碰撞深度。480,000次混合探测/轮、交替七轮的CPU微基准中位30.04ms→7.70ms；只是该工作负载的碰撞函数耗时，不表示整款游戏提升74%。

## 本机核对与限制

静音、禁云/本地存档和地图缓存的专用页面使用用户本机Intel Iris Xe WebGL，1280×720、pixelRatio1.25，无viewport覆盖。原画质同视角的前后采样均为2017次绘制、1,115,974三角形、1051个已上传几何和107个已上传纹理。全场材质4272、纹理652、点光51和聚光8数量保持。地形异步队列完成程度不同，不能把场景对象数、JS堆快照当作内存泄漏或收益对照。

浏览器采样包含首次渲染约3–4秒高峰，仍有较重的渲染开销。自动化前后rAF调度不一致（约1016ms与100ms），不是自然前台FPS，不能承诺60帧或卡顿全消失。浏览器阶段统计仅用于定位；最终性能数字来自上述串行隔离基准。

## 对话与回归

普通NPC先用底部小点打开话题，选择后阅读回答；最后的小点/Enter直接关闭并恢复游戏，不再绕回话题列表，也不必找右上角结束。再次互动重新显示初始问候和话题。主线末句已有的关闭与推进保持。真实地铁安检员问答已在本机验证，最后Enter返回游戏，控制台无错误。

定向测试涵盖网格的十个发布版字节基准（真实街区、边界、空块与32位索引）、增量队列、人车精确相交、倒车脱困、南京路信号及行人、通勤、行人回退、个人建造兼容、基础世界恢复、缓存、主线、NPC结束/重开、云存档和互动路由。未扩展旧交通长循环基线问题，不称整套npm test全部通过。

主存档版本6、地图修订11、基础地图缓存69保持；无生成内容变更，不清缓存或玩家存档。专用页面和原始性能文件均不进入正式发布包。
