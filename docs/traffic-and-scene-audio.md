# 交通与区域声音

汽车、公交与骑手共用车身避让检查。旧逻辑只比较相同路线对象，骑手与汽车路线重合时无法识别对方；现在所有路线按实际位置、朝向、宽度和长度判断重叠，以不超过 1/30 秒的步长移动。骑手优先选择整条路线都有净空的路边车道，生成时错开间距，各自具有不同速度与相位，弯道减速。红灯队列、同车道安全距离和公交停站继续保留。它是轻量交通模拟，未加入完整刚体与事故系统。

交通不再因玩家靠近或驾驶碰撞而暂停，也不会被 NPC 踉跄动画移动。来车接触玩家时，寻找最近且有地面支撑的清晰落点，将玩家或玩家驾驶的自行车／汽车推开；自动车流继续，生存模式扣生命、创造模式给提示与红边反馈。搭乘公交的玩家随公交行驶，直升机沿用原来的飞行碰撞规则。

区域配乐默认开启，南京路与沿街店铺播放“南京路漫逛”，龙凤厅播放“龙凤茶叙”，水下／生活岛／日夜城市匹配其余曲目。跨区域停留 1.2 秒才切换，避免门口抖动；手选曲目或点下一首后关闭自动匹配，可以在暂停菜单重新开启。所有曲目与环境声音为程序合成，没有第三方录音。

环境声包含靠近车辆时的发动机声（车速决定音高，方位决定左右声道）、临江水声、雨声、步行脚步、进店铃、餐具轻响、公交停站提示和碰撞短鸣。近商贩时每隔至少 24 秒尝试一次中文吆喝，使用浏览器已有的本地中文语音；没有可用语音则跳过。暂停、静音、隐藏页面、关闭环境音都会停止环境声和吆喝。音量滑块同时控制音乐和环境声音，音乐与环境音可分别开关。

实现依据：Web Audio [平滑参数变化](https://developer.mozilla.org/en-US/docs/Web/API/AudioParam/setTargetAtTime)、[左右声道定位](https://developer.mozilla.org/en-US/docs/Web/API/StereoPannerNode/pan)、浏览器 [语音列表](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices) 与 [本地语音标识](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisVoice/localService)。语音可用性取决于浏览器和系统，不承诺每台电脑都能吆喝。

验证：`tests/traffic-scene.test.mjs` 连续运行真实城市两分钟，逐步检查所有车辆／骑手无重叠，所有交通工具有前进；检查玩家碰车的安全推开与车流不受冻结、区域判定、手选覆盖、音量衰减及暂停／静音／缺少语音的行为。原有驾驶、公交搭乘、桥坡和下机检查继续运行。本地独立浏览器试玩禁用存档写入并静音：30 秒车流无重叠，玩家碰车能退到无碰撞位置且车流继续，南京路与龙凤厅切曲正确。保留轻量合成声，未将其描述为实地采样。
