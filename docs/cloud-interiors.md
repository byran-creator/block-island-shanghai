# 云上书院与江景阳台

和平饭店原套房临江面为整片玻璃碰撞，`balcony`未开启，室外也无支撑。现中央2.4米门洞衔接真实阳台地板，按玩家0.29米半径保留门边玻璃阻挡；外沿玻璃护栏、金属扶手、两侧花箱和临江长椅避开中央通道。长椅可坐、起身，保存时记录可用的站立出口。坐姿只降低相机，不将玩家埋入地板。原汤臣套房的阳台仍在原侧。

和平饭店大堂新增可见客梯，同面板选择1F、8F龙凤厅、江景套房，餐厅和套房也能返回。保留原餐饮、浴缸、电视和套房持久状态。

上海中心沿用原螺旋外形，增加可从街面步入的大厅和实体电梯门。电梯停靠大厅、办公体验层、52F朵云书院、原空中花园及原巅峰观景台。内部游戏坐标46/66采用既有压缩比例，不对应现实楼层高度。新增区域的透明幕墙独立于室内显隐，远处仍保持楼体轮廓；安全碰撞按整圈幕墙而非只挡正面。

办公层复用原陆家嘴 tower-offices 区的两名职员。在初始化日程前提供可选 `workplace`，让两人沿真实铺装走到上海中心内侧门点；工作时在办公层显示同一角色。每帧寻路前恢复逻辑坐标和姿态，日程仍在地面连续行走，晚间回原住宅。室内不是街面NPC的副本。原18人数量及其余工作地点不变，任务约谈机制保留。

朵云书院以连续白色山形/拱形书架、两面彩色书脊、浅色地面、蓝绿咖啡角、粉色陈列台与临窗阅读座组合。三本可翻阅的文字均为本游戏原创旅行短读，不复制出版书籍正文。末页直接合上，感想通过原人物留言接口收入旅行手账；每本只占一个去重条目。临窗可坐，移动或V起身。附近翻书、坐椅时收起重叠电梯提示。

室内装饰合并成49个静态网格，两个职员复用，不新增实时光源或独立角色预览渲染器。仅在玩家附近楼层显示室内家具，玻璃幕墙独立显示。阳台和书院适当延长局部雾距，沿用现有地形加载范围，不扩大全城加载半径。

基础缓存更新为 `peace-duoyun-walkable-interiors-v84`，防止继续读旧楼层几何。玩家存档版本6、地图修订11不变，个人方块记录照常回放，浴缸电视、物品、旅程和收藏不重置。

## 验证

`tower-interiors.test.mjs`验证真实体素地面的房内→门洞→阳台路线、街面→两栋楼的电梯通道、长椅坐起和保存出口、每层到达点、整圈幕墙、三本短读、两名职员实际上班及回家、工作显示恢复、五层电梯往返，以及静态网格上限/无新实时灯光。配合原餐饮套房、世界缓存、剧情、上下班与发布回归。

发布回归曾发现原步行器将不足2厘米的目标步幅替换为固定朝向，而原日程把绕圈的位移当作进度。大厅开放改变了最短步行路线，触发酒店回程无法完成。现保留所有非零步幅的真实方向，并按到当前路点的距离减少判断进度，5秒无实际接近则从当前位置重算路线；不瞬移、不放宽人距。新增30/60/120/240Hz慢行方向断言，原临时障碍恢复、玩家堵门释放、两天自然日程通过（18人、116次真实门内到达、最小人距0.90000011米）。
