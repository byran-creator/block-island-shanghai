# 站口门头、真实方向、海关钟面与南京路人群 · v37

## 站口

原站牌宽7格，横跨南京东路窄站口，两端伸进沿街店铺墙面。移动支柱只能解决支柱遮字，不能解决牌面和建筑重叠。本次四个入口均新增金属框、玻璃侧墙和遮雨顶的门头，站牌直接贴在门头与侧檐。南京东路站口随现有窄扶梯设置紧凑门头，陆家嘴入口相应较宽；牌面采用匹配比例的中英文字、绿色2号线标识和出口号，不再用横跨街道的大牌。

门头放在扶梯前方已有平坦入口范围内，保留四个入口地理位置、坡度、B1安检/检票与B2站台。实际体素检查确认四个牌面和雨棚均不嵌入店铺墙体，并保留行人净空。站口外观为游戏原创建模，采用压缩尺度，未宣称严格复制真实站口建筑。

## 真实行驶方向

原站台两站共用固定“陆家嘴方向/南京东路方向”，所以已经到达陆家嘴仍显示往陆家嘴。现按所在站和行驶方向分别显示：南京东路往东为陆家嘴、往西为人民广场；陆家嘴往西为南京东路、往东为浦东南路。浦东南路之后为世纪大道。

东昌路已在2024年更名为浦东南路，见[上海市政府发布的更名说明](https://www.shanghai.gov.cn/nw4411/20240922/f5fd81dbfe9244a298fd13806c993ca3.html)。站序核对[上海市政府转载申通地铁的线路图](https://english.shanghai.gov.cn/en-Latest-WhatsNew/20240924/b625d488216241f78f743cd87a40df0c.html)。车门上方线路条同步改用现名，列车到达体验区边界时显示真实下一站。游戏仍只开放南京东路—陆家嘴两站，灰色相邻站未开放；不是增建新站或允许列车载玩家驶出体验区。

## 海关大钟

已查看来自乐游上海的[海关大楼介绍及实景近照](https://m.thepaper.cn/newsDetail_forward_16732846)，包括[钟面近照](https://imagepphcloud.thepaper.cn/pph/image/179/880/976.jpg)。参考白玻璃圆盘、黑色罗马数字、外圈分格、中心花纹与较宽铜制指针，绘制原创1024像素钟盘纹理，移除通用方形底板。钟楼四面共用一张纹理，增加薄金属边框、中心轴和长短指针。

长短指针在钟面内按顺时针转动，时针包含分钟偏移，与游戏时钟一致；夜晚为暖白发光钟面。图案是按实景特征重绘的简化版本，不是直接贴上照片，也未修改钟楼位置、体素高度或增加报时音频。

## 人群根因与修复

南京路原有两套行人：活动模块43名步行游客/配送员，以及外滩模块12名购物游客。前者仅检查自己的同组间距，后者沿独立矩形路线运动，双方没有避让。修复前完整场景90秒模拟记录到1220次跨组重叠检查命中；单独运行43人则没有同组永久停滞，说明两组互不避让是关键原因。

55人现由同一个人群控制器更新，原12人不再被第二套路线覆盖。目标只选择可通行位置；遇阻允许侧移、退让，不再只尝试向前的小角度转向。人与人间距扩大至0.9格，考虑购物袋与手臂外伸。进一步修复小幅挪动不断清零受阻计时的僵持：排除正常逛店停留，三秒未移动半格就寻找退让空间，而非继续向同一目标挤。独立速度、逛店停留、外观与角色标签保留；不通过瞬移或隐藏人物消除拥堵。最终两分钟联合回归，最后一分钟最少移动14.88格。
