# 地铁细节修复 · 2026-10-07

安检机、立柱、站台座椅和闸机隔断现在使用相同的实体边界检查玩家与站内乘客。原先乘客直接按正弦函数写入坐标，出生点和摆动范围都未检查设备，导致有人站在安检机中。现在先寻找整段运动都安全的站位，移动时再检查；同时保留安检操作与刷票路线的空位。两站各34名乘客的数量不变。闸机玻璃隔断原先伸进实际通道，已同时修正模型和碰撞边界。

站内导向改为黑底白字、中英双语、绿色2号线编号、单独箭头的薄型吊牌。站厅牌提升到地面以上约4.25米，站台倒计时牌底部约3.63米；减少悬吊牌的宽度和高度，将重复站台提示移到侧墙。V等操作按键继续在屏幕提示显示。保留原站名、入口位置、到站倒计时和原有安检/乘车流程。

演唱会灯箱直接使用用户第二次提供的完整竖版海报，保留原图人物、华晨宇火星演唱会名称、日期和场地文字，按原比例显示于4.1米高的竖版灯箱，不叠加额外文字条、不裁剪拉伸。JPEG为高质量压缩，全部灯箱复用一个纹理，图片无需外部网络加载或存档结构变更。工作人员对白标明玩家提供的演唱会图片，不称其为游戏原创。

本批追加列车到站前5秒开始的轰隆声：Philt3r在Wikimedia Commons发布的伦敦地铁1996 Stock进站实录（CC BY 4.0），截取播放前5.6秒、低通与音量渐入渐出。声音逐渐靠近并减速，不以提示旋律代替车辆声。游戏内菜单链接audio-credits.txt记录作者、来源、许可和修改，不冒充上海2号线实录。声音在玩家进站且开启声音后异步预解码并缓存；失败时使用本地合成滚动声。安检放包/完成短提示音是原创合成，安检员仍使用可切换普通话/英语嗓音。暂停、后台或关闭声音时停止已排队音源，缺少音频/语音能力时正常保留字幕与操作。

夜影现有移动本来已有短步碰撞检查，但默认使用玩家边界，而夜影身体略宽。现在扩大到夜影身体边缘；新放置的实体包住夜影时将其清除，不让它继续在墙内移动。被墙隔开的玩家不会持续触发直线追逐，视线检测每0.35秒缓存一次，避免每帧重复射线；攻击仍要求无遮挡。没有新增穿墙能力或改动夜影奖励。

- 实际查看[上海地铁虹桥2号航站楼导向升级照片](https://sghexport.shobserver.com/html/baijiahao/2021/07/27/496658.html)：黑色吊牌、白字、箭头、中英分层与绿色2号线徽标。借鉴风格，不复制照片作为游戏纹理，也不声称本游戏完整还原该站。
- [Mojang幻翼卡进方块问题记录](https://bugs.mojang.com/browse/MC/issues/MC-239111)：MC幻翼与本游戏夜影是不同的生物；穿模不作为正常设计保留。
- 新回归：两站68名乘客连续六分钟无安检机/立柱/座椅重叠，并保持运动；安检交互点可达。
- 原地铁回归：安检、刷票、双向实际走入车厢、连续地板、开门、下客、存档与静音通过。任务目标与实际路线检查通过。
- 夜影：确定种子下三分钟实际生成与追逐，9585次全身体墙面检查无穿越；新墙包住实体时清理、阻挡出生也通过。
- 独立静音浏览器：玩家向安检机步行，停在外侧且未卡入设备；放包后成功安检；站厅吊牌和完整海报灯箱已实际查看并保存截图。QA入口禁用所有存档写入，发布前移除。
- 音效回归覆盖实录/滚动后备、放包与完成声音、同一AudioContext缓存、静音、暂停取消和音频不可用降级；浏览器验收保持静音，没有播放声音打扰用户。

这是一批地铁与夜影修复，塔冠广告、增加城市NPC总人数等先前待办未混入本次修改。
