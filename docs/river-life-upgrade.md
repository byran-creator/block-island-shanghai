# 江景生活更新与验证（2026-10-05）

## 设计依据

方块化游戏中的定制套房参考真实建筑和室内材料，不是酒店实际户型复刻。

- [和平饭店官方 Sassoon 套房](https://www.fairmont.com/fr/hotels/shanghai/fairmont-peace-hotel/rooms/SassoonSuite.room.html)：深木饰面、奶油色家具和吊灯。
- [汤臣一品官方介绍](https://www.tomson-group.com/product/20.html)：高层江景和阳台。
- [上海官方外滩日夜景](https://english.shanghai.gov.cn/en-ScenicSpots/20231205/584672cc6d044eabb5f7f6fc9049a19f.html)：白云、天空层次、滨江夜色。
- [文汇报外卖电动车照片](https://whb-oss.oss-cn-shanghai.aliyuncs.com/zhuzhan/cs/20190225/244350.html)：前挡板、踏板、电池车身、头盔和配送箱。
- [上海中心照明项目](https://www.traxon-ecue.com/project/shanghai-tower/)：塔冠媒体照明。游戏文字为自制宣传内容。

没有取得可核验的新雨天实景照片，因此保留既有雨粒子造型，仅改善云光和变化速度，不声称写实复刻雨景。

优化包括静态街具/站厅/云/套房合批，以及删去驾驶镜头的重复区块更新。分辨率降低也是收益来源；这是短时本机观测，不是同渲染分辨率对比或普遍性能保证。机器约15.6GiB可用总内存，采样时约2.7GiB空闲；不能据此确定全部卡顿由内存不足导致。

## 验证与存档

- 完整18组测试通过；套房栏杆与朝向调整后，river-life及commute-travel再次通过；最终云水渐变通过atmosphere检查。
- 两套房步行到门口并返回大堂无碰撞；汤臣实体阳台可达且有支撑。
- 普通角色从船上方落到甲板，脚部y24.64，已落地且无卡墙；真实动画后位置随船变化，局部坐标仍为(0,1.8)，甲板支撑保持成立。
- 轮渡往返均成功到岸，途中没有挤进码头；2分钟交通模拟全体保持移动且无车辆/骑手重叠。
- 保持MAP_REVISION11及玩家存档结构，基础缓存改为city-life-2026-10-05-v5；升级首次重建基础世界，不清理玩家存档。
- 浏览器试玩使用独立静音入口、禁用存档写入；这些入口不进入公开构建。
