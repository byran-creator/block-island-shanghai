# 实例变换检查顺序 · 2026-10-23

基线main `71190ad`。外滩持续帧采样指向实例更新与绘制提交。本轮先尝试按字节识别重复小几何，但新增检查和实例处理抵消了绘制调用收益，三组对照没有稳定的整帧改善；该候选已撤回，没有进入正式代码。诊断保留在本地 `qa/geometry96-rejected.json`，不得将其22%绘制调用下降当成本次正式版成果。

最终候选只调整 `scene-instancing.js` 的检查顺序。原循环在视锥裁剪前为每个来源计算完整行列式和正交性，即使其在屏幕外。现在仍先处理场景脱离、几何/材质替换及透明变化，再按原包围球和原视锥裁剪；确实需要绘制的来源才检查镜像/剪切是否支持实例变换。原始矩阵、裁剪公式、材质、几何和实例上传均不改变。

画外不支持的变换此刻在两条路径都不绘制；进入任何相机视野的当帧立即核对并恢复原绘制路径。`frustumCulled=false` 的来源照常核对，不借此隐藏内容。隐藏对象、返回视野、镜像/剪切、材质/几何替换、移除对象和释放继续保留原行为。

新增确定性测试：1000个来源仅10个在视野内，变换行列式检查从原来的1000次减至10次；验证画外变形后回到视野的即时回退、显式裁剪豁免及画外替换。既有实例/Canvas回退、完整城市24镜位和上传测试通过；城市批次320、来源6390、13163个动画矩阵对照保持。该局部计数不能换算手机FPS。

完整WebGL诊断固定画布1055×487、MSAA、seed96、模拟步和转向路线，静音禁存档；测量前完成相同地形队列，运行接口仍启用。100帧排除前20，四个镜位读取像素仅用于QA。它衡量稳态帧函数墙钟耗时，不是独立GPU时间、真实手机帧率、首次进入或跨区加载。本轮不降低清晰度、人数或视距，不变更灯光、交通、任务、存档及玩家建造。
