# 两岸建筑轻量精修 · 125

本轮是外观细节扩展，不是性能优化。保留原体素轮廓、建筑尺寸、人数车流、视距、灯光与画质；远景轮廓变化小，主要改善近景材质和立面层次。

## 实现与资源责任

- `shanghai-textures.js` 在原 256² 石材、古典日夜窗、铜屋顶纹理内增加刻线、窗台/窗楣、分格与接缝；不扩大既有纹理。不使用实时反射、法线贴图或新光源。
- 现代裙楼立面使用一张 128² 中性玻璃贴图；按现有颜色复用材质。每面重复量写入自身几何 UV，不修改共享 texture.repeat。纹理沿用该模块已有的有限应用生命周期缓存；使用者只引用，不各自 dispose 共享纹理，不能在活跃场景中清池。
- `landmark-finish.js` 只在创建外滩场景时读取三塔现有外露玻璃格，合并连续银色饰条；不会生成每窗对象，不越过门洞/环球顶部开口，不写地图。3 个临时源几何并入原有银色材质批次后立即释放；最终批次归原场景所有，局部单位矩阵、父级世界坐标更新和原批次释放责任保持。
- 不新增 tick、动画、碰撞、网络请求、实时灯或运行时全城扫描。玩家存档、Save6/Map11/Cache84 及默认地图数据保持不变。
- 首次欢迎页仍用原上海实景照片。点击后的加载页使用本版原生游戏截图，仍为 2731×1263 JPEG，相同构图/解码像素数；445329B，较上版增加6678B。旧哈希图片留作已打开页面的兼容资源。首页公告手动查看，历史公告保留。

## 预算与验证

Node24.12 完整构造诊断（假 Canvas，仅比较资源结构）原/新：15047对象、11669 Mesh、3849 Geometry、3740材质、315实例批次均相同；纹理523→524。新饰条1052三角形，测试上限1200。最终几何属性/索引缓冲增加105200B；共享128² RGBA含mipmap的理论增量约87381B，不等同实际显存或进程内存。

原始本机记录：`.local-data/qa/resource125-baseline.json`、`resource125-candidate.json`；不将假 Canvas 的绝对纹理内存估计或单次构造时间当作手机性能。

`landmark-finish.test.mjs` 验证不写世界、每片饰条对应真实外露玻璃、开口不跨越、共享128²纹理和固定repeat/资源预算；既有静态合批字节、变换、实例化、室内、地图基线与启动入口测试继续使用原断言。固定画质完整转向采样另记下文，不把桌面CPU墙钟换算手机FPS。

未来扩建继续优先原贴图、原网格 UV 与同材质合并。任何新增批次/材质/每帧更新须记录前后成本；不为外观升级降低画质或减少人流，也不凭“静态”关闭父级 world 更新。
