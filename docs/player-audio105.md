# 持续脚步与本地加载片段（2026-10-25）

## 已定位问题

104仅在独立节奏器中输入walking=true验帧率，未覆盖实际物理触地。真实physics使用while(remaining>0)，最后浮点极小子步位移小于overlaps的.001容差，虽先前有地板接触，最终grounded仍会false。按原真实函数复现：20/30/40fps六秒持续步行可为零脚步。

105只另记本帧已有的地板接触footContact，不改原grounded、速度、位移、碰撞或子步循环；跳起时清接触，竖直速度阈值阻止空中脚步。新增回归执行实际physics和实际音频walking表达式，20/30/35/40/60/61/75fps六秒各20声，飞行/滑翔/跳起不响。本地3852帧行走/跳跃物理状态逐步与c850511完全一致，NPC PCM字节也与原版一致。

## 玩家音色

原100Hz正弦鞋跟成分造成低频用力踏地板感。参考Minecraft 1.21.1官方资源目录中的step/stone1与grass1，仅在忽略的本地QA目录分析，不分发这些资源。玩家另用原创带限噪声短鞋底接触/摩擦纹理，草地/木板/石地三个小缓存，共用原音源清理与四源上限；NPC沿用原buffer/增益/步频。玩家低于180Hz的一阶低通能量占比约.0643，NPC原波形约.6610，属于信号验证而非主观听感达标。新增PCM总上限28,800字节，按首次踏上对应材质创建，重复脚步不再创建buffer，销毁释放缓存。

## 加载音乐

104外链存在HTTPS跳转HTTP及外站等待，且城市准备完成就停止，使短加载/首次手势恢复容易听不到。本轮把已获用户指示用于临时同学体验的《上海滩》0–22秒片段作为176,795字节同站MP3，文件名SHA256前12位，后续替换必须换哈希。Worker对此不可变资源长期缓存；不改个人存档API/no-store。音频无JS整曲解码，浏览器负责有界媒体缓冲，静音时不设置src，不请求文件。来源、处理和临时用途见game/audio-credits.txt。

默认尝试播放，不更改浏览器权限；NotAllowedError在原配乐文字旁显示等待正常交互许可，静音/失败分别显示状态。保持到初始菜单，真正enter时停止、取消请求并释放监听器，再由游戏内配乐接管；ready不再过早切断，迟到loader用gameStarted判断而不是gameReady。消除点击进入后先启动游戏配乐、恢复存档后又启动一次的重复初始化。首次有声播放仍可能被浏览器拦截，不能承诺无手势强制发声。
