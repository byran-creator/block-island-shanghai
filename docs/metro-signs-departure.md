# 地铁离站音效与参考牌面 · 2026-10-07

本批只调整列车离站声音和标识，不改变车站位置、安检/检票、登车地板、班次和存档接口。

## 标识根因与设计

上一版统一使用1024×256纹理，但牌子实际比例各不相同，例如8.5×0.75米的宽牌，导致字形横向拉宽。柱牌、入口和侧墙牌也还在使用旧的居中通用文字样式。现在纹理比例随实体牌面比例生成（最长4096像素），文字只等比缩小，不沿横向压缩或拉伸。

结合玩家给出的四张参考图，以及[上海交通发布的2025陆家嘴站导向更新实景](https://sghexport.shobserver.com/html/baijiahao/2025/03/26/1536696.html)，按用途分别设计：站厅采用黑底分区、白色线路信息、绿色2号线编号、黄色出口编号和箭头；站外入口采用黑底站名与出口分区；柱牌和站厅墙牌改为白底黑字、绿色横带和中英站名。墙面大站名牌移到立柱之间，放到负侧实体墙的内表面，修正原先藏在体素墙内的问题。吊杆接到顶棚，通行净空保持。

每扇车门上方增加白底线路条：绿色南京东路—陆家嘴区间、圆形站点和上下交错的中英站名，随当前列车的方向/停站/运行状态显示下一站。相邻人民广场、东昌路、世纪大道为灰色地理示意，并明确注明暂未开放，不作为已建成的站点或可乘坐目的地。用户旧图中的“河南中路”等不照搬为现站名。每列车全部线路条共享一个纹理，两列车仅两份，状态改变时更新，不逐帧重画。

## 离站声音

声音从真实列车状态“停站→行驶/驶出体验区域”触发，站内玩家与乘车玩家都可听到。牵引电机音高从低到高，叠加滚动声，先增强后淡出，持续5.6秒。同一次出发不会每帧反复触发；暂停、后台、声音关闭仍立即停止音源。

离站声音为原创程序合成，没有冒充上海2号线实录。搜索并查看了[Chunhui Tang发布的上海4号线AC-05运行录音](https://commons.wikimedia.org/wiki/File:上海地铁AC-05电客列车运行_Shanghai_Metro_AC-05_Train_in_Opertion.ogg)，其为CC BY-SA 3.0的4分15秒长录音；本批没有确认适合用于2号线进出站短片段，未下载或打包。现有许可明确的伦敦进站实录保留，来源与许可见[音频署名](../game/audio-credits.txt)。

## 验证

- 双站各一分钟运行：每站两次实际离站，均只触发一次；电机音高上升、滚动缓冲复用、静音/暂停/后台回归通过。
- 原地铁登车、地板支撑、开门、下客、安检刷票、双向通勤与存档回归通过；68名乘客六分钟设备避障与任务指引回归通过。
- 标识比例、白底站名、黄色出口模块、中英线路条、每列车单纹理和悬挂净空检查通过。
- 实际浏览器静音验收站厅、站名牌、车厢线路条，无脚本错误；离线音效渲染六秒，第二秒强于第一秒，第六秒低于第三秒，未播放出声打扰用户。
