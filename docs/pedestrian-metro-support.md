# 行人车身碰撞与地铁支撑修复

本次保留城市、存档格式和地下体素隧道，不需要清空存档或重建城市缓存。

- 行人移动使用与交通相同的旋转车身碰撞检查，沿移动路径逐段检查，不再只由车辆单向避让行人。街头游客、外滩散步者、楼宇居民都接入；车辆初始化避开已生成的行人和交警。
- 旧散步路径部分落在外滩车道、北面桥头转弯和拓宽后的弯道内。现在依据道路边界安排在滨江人行区域；南京路游客的折返点留在人行区，交警站在车道外。
- 列车整个车厢提供随列车位置和转角变化的地板支撑，站台间隙保留连续支撑。开门走入自动登车，V 仍可辅助；进入车门时自动结束飞行和滑翔状态。
- 体验终点的到站列车也可安全进入，关门前自动回站台；跨江返程乘对面站台列车，不让角色随列车驶出游戏范围。
- 地下环境范围覆盖轨道底部正常落地误差，保持封闭隧道、地下雾色和隐藏江面；不会把轨道地面误判成游泳区域。

验证：新增三分钟真实场景行人/交通共同更新测试，包含公交、游客、散步者、居民和交警，检查可见人物与车辆没有交叠，并检查最后一分钟所有车辆继续前进。既有九分钟交通和停放车辆绕行测试通过。浏览器实际 physics 验证两站双向、飞行状态、略偏门中心和终点到站列车共七种无需 V 的登车情况；另检查车厢内部支撑以及 y=2.998 的地下轨道环境。
