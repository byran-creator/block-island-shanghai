# 南京路路面与双向车道对齐

用户截图指出：石碑路口相邻的南北道路看起来仅有窄路面，另一侧车辆驶在铺砖区域。此前仅检查逻辑道路半宽和体素车身净空，不足以验证可见沥青范围。

根因是 `PlaneGeometry` 转到水平 XZ 平面后，局部 Z 旋转用了相反符号，弯道被镜像，连续短路片形成锯齿。车辆继续沿正确采样曲线行驶，因而不在黑色路面上。南京路两侧道路 40..100 范围，修复前 574 个双向车道中心采样有 234 个不在实际沥青三角形中；修复后为 0。

仅修正黑色路片、中央虚线和非机动车道涂层的旋转符号，保留每方向一条机动车道的既有宽度及车流、行人、建筑、地形、红绿灯逻辑。无需变更城市缓存或玩家存档。

新增 `road-surface.test.mjs` 读取静态合批后的真实路面三角形，检查路口两侧两条南北道路的双向公交完整车身九点覆盖，以及非机动车道实例矩阵的方向。保留既有净空检查，避免再次只依据逻辑宽度下结论。没有 GPU 试玩，不声称整个城市所有复杂路口的视觉问题已验收。
