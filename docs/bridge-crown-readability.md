# 南浦桥坡道对齐与上海中心广告 · v40

## 桥面与车辆

根因并非桥梁高度数据：旧模型用“从Z轴转到坡道方向”的最短旋转，沿X轴的下降坡同时带出了横向倾斜。6米宽坡道两侧可产生约1.41米高差，实际车辆与人物却使用横向水平的高度函数。车辆原XYZ旋转顺序又将坡度施加在世界轴上；向东/西开的车会侧倾，前后轴并未真正随坡道升降。

桥面改用明确的前进、水平横向与表面法向构建旋转基底：沿坡道倾斜，横向水平。玩家汽车/自行车以及道路交通采用YXZ旋转顺序，使俯仰发生在车头对应的局部轴。桥面路皮和车道线也变薄，贴近既有物理高度，避免厚路皮掩住车轮。

桥梁位置、宽度、坡道高度函数、车流路线、世界体素和缓存版本保持原样。

## 塔冠广告

旧1024×256横版纹理被映射到高而窄的四分之一环面上，汉字被拉成细长字；外滩正面又接近重复纹理的接缝。实际近景还发现U坐标方向相反导致左右镜像，阶梯状塔冠及观光平台边缘遮住部分笔画。旧时段在22点关闭，与菜单常用夜晚预设冲突。

采用共享512×1024竖版贴图，竖排轮播“上海 / 欢迎 / 夜游”，每个字占据更宽的可视面，不再使用maxWidth横向压缩。四处重复的接缝转45度，使外滩与其他主要方向面对完整词的中心；修正贴图左右方向，并按实际体素台阶为外层屏幕留出净空。广告自身提高远处对比度，不改变整个场景的雾或画质。显示时段为游戏时间18点至午夜，保留每8秒换词；金茂裙楼屏时段不变。

屏幕只朝外显示，避免在塔顶观景台内部新增遮挡。广告是游戏原创文字显示，不代表现实塔冠实际投放内容。远景字号仍受观察距离和屏幕尺寸影响。

## 验收

- 两侧坡道横向水平，长度跟随真实坡度；实际生成的东岸桥面顶点与碰撞高度相符，实际车流与玩家载具俯仰不产生侧倾。
- 双向驾车穿过完整坡道，高度平滑；15分钟全城车辆/骑手碰撞、最终前进和停车障碍恢复回归通过。
- 广告贴图比例、未压缩字形、正面完整词、左右朝向、体素塔冠不遮挡及22点之后显示回归。
- 实际浏览器静音且禁存档：东岸坡道三车姿态样本侧倾0，桥面、外滩正常视角和塔冠近景均查看；改正了第一次近景观察发现的镜像/遮挡问题。
