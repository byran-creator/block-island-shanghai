# 2026-10-04 本地试玩反馈

用禁用存档写入的独立页面，调用正式游戏模块试玩，没有覆盖玩家的磁盘存档。

已实际检查：地图打开与南京路传送；同一路段一秒步行 4.50 格、跑步 8.50 格；自行车搭乘、移动和下车；汽车搭乘与障碍前停止；公交停站登车、跟随线路移动；白玉兰直升机搭乘、两秒上升 18 格，以及悬空下机保护；夜间灯光秀。

发现并修复：公交跟随镜头经过观景台时，悬浮地名牌会因距离过近放大遮住视野。外滩与地标导览牌现在在距离镜头四格以内隐藏。实际公交视角复查没有出现此前大面积的提示牌遮挡。

自评：传送和快跑明显减少长距离步行，公交及直升机让两岸通勤有更多选择；但小窗口中任务面板、地图与物品栏占用偏多，可驾驶车辆的辨识提示仍可加强，首次生成街区需要等待。普通填充楼仍是风格化模型，并非完整实景复刻。载具的位置目前不随存档保存，也没有多人联机功能。

验证：全部 11 组 `npm test` 检查通过。测试页面曾因测试按钮误用公交数组路径报错，已修正测试工具并复查；这个错误不在正式游戏入口中。试玩截图保留在本机 `.local-data/qa/playtest-*.jpg`，不打包上传。
