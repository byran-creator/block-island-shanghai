# 人物贴图细化 · 2026-10-07

用户要求人物贴图完成后先暂停，因此本批仅修改现有人物外观。塔冠广告、任务追踪和增加NPC人数留待恢复；未完成的准备代码保存在.local-data/pending32，未接入发布版。

## 核看的参考

- [Minecraft官方皮肤说明](https://www.minecraft.net/en-us/article/what-is-minecraft-skin)：已查看Steve/Alex实图，参考方块人物的像素面部、发型、服装分区与深浅关系。实际查看图片为https://www.minecraft.net/content/dam/minecraftnet/games/minecraft/key-art/skin_stevealex.jpg。
- [上海长宁区官方交通安全活动照片](https://www.shcn.gov.cn/col3991/20230801/1241250.html)：已查看浅蓝制服、深色肩章、胸袋、纽扣及普通职员服装。实际图片为https://cn.storage.shmedia.tech/3193db9fd50d4c15b9a01cde9016d7dc.jpg；第二张会议照片也已查看。没有据此声称复刻反光背心图样。

采用自绘Canvas像素图集，没有下载或复制参考图片/官方皮肤作为游戏素材，也没有复制真实证件编号或徽章。

## 实现与范围

给游客、商贩、职员/住户、地铁乘客/安检员、交警和骑手增加面部、发际线、衣领、口袋、纽扣、袖口、裤缝和鞋边细节。四组肤色与发型变体，按角色使用不同衣服配色。脸只画在头部前侧，其余各面使用对应头发、侧面或衣料。

各人体方块尺寸和位置保持；图集96×64，六个32×32面，按角色/变体/身体部位缓存共享。最近采样保留像素细节，缩小使用mipmap。软件渲染沿用已有纹理三角形路径，无DOM的物理模拟测试仍有纯色材料回退。楼宇身体继续合批，动作和碰撞接口不变。商贩与顾客朝向柜台彼此，避免有了正面贴图后背对交易。

没有增加人数：浏览器检查外滩行人45、南京路游客51、楼宇居民18，与原构造数量一致。地图缓存、存档、任务奖励和通勤规则不变。不宣称新增贴图能提高帧率。

## 验证

npc-appearance覆盖六面UV边界、细节绘制、角色差异、材料/图集复用、几何边界保持以及软件纹理支持；city-activity、metro、river-life通过。原pedestrian-traffic十二分钟模拟通过793791次人员/车流检查，最终车辆均有进展，没有新增长期卡住。浏览器静音、禁存档检查游客与交警实际面部和衣服，无脚本错误；临时近景页面不发布。
