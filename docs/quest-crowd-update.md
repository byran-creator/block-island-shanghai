# 可选任务追踪与南京路人群 · 2026-10-07

本批集中处理新手按需引导、南京路人群独立节奏和面部差异。塔冠广告与进一步增加NPC人数留作下一批。

## 按需引导

新游戏和没有追踪字段的旧存档默认不追踪，不弹出强制教程。按I打开任务栏，可选“追踪目标”或“地图查看”；选中后HUD显示下一步操作、目的地、水平距离与方向，地图有黄色菱形，近处有空间标记。可以随时停止；领取奖励后停止当前追踪，不自动安排下一项。明确选择的追踪任务随原存档保留。

8个城市任务都有相应目标。地铁引导分为地面入口/入口扶梯/B1安检/闸机/走过闸机/B2扶梯出口/离开坡道/对准候车门/开门进车/过江后下车。扶梯和闸机分阶段，避免直接斜穿护栏；候车先对准门，门开后才标记车厢。黄色标记点击只提示操作，青色景点或下方按钮仍可传送。

它是目标和关键通道提示，不是全城自动寻路或自动代玩。街区仍需要自己沿路探索，保留NPC和路牌。到达目标、地图传送、未完整乘坐均不能替代原完成事件；奖励仍只领取一次。任务内部状态升级为2，整体存档保持6，原任务进度与奖励保留。

## 本次进站安检

上海[2025安检工作规范](https://www.shanghai.gov.cn/202513bmgfxwj/20250807/1b6f7476a4234b2c91efe929072c4f42.html)说明对进入车站的乘客和随身物品进行检查。游戏以一次进站为有效范围：公共站厅可直接下去，安检刷票后进入站台；仍在站内的乘坐/折返不反复安检。出闸或离开站内（包括传送到地面）结束本次安检，再入站重新检查。站内读取存档可以继续该次行程；没有更改背包物品。离开站内时尚未完成的安检会取消并取回背包，不虚构完成。

## 人群与脸部

旧南京路动态行人均以0.9格/秒在两条固定直线上往返，初始化间距也是规则数列。现在各人使用独立种子、0.58–1.32格/秒速度、不同横向位置、目标、步态相位及浏览停留；部分人一开始走、部分人停留，避免同一批同时起步。改变方向连续行走，不在运行中瞬移。遇到人群、车辆、建筑和柜台检查让行，受阻后换目标。原40个游客、3个步行送餐者和柜台顾客数量保持。

面部由4组主要配色扩展为8种组合，眼睛高度/形状、眉毛、嘴型、发际线、眼镜和少量胡须有所区别；不是每个NPC唯一头像，会复用组合。头部图集仍96×64，身体部分维持4组复用，不改变碰撞或几何尺寸。沿用上一批实际查看的Minecraft像素人物和上海制服照片方法，自绘纹理，无新增下载图片。

## 验收

新增quest-guidance覆盖各地铁阶段、目标支撑、地图坐标、旧追踪兼容和不伪造完成；street-crowd覆盖双分钟独立速度/停留/横向分布、连续运动、人与人间距和进展。原city-quests、metro、npc-appearance和city-activity通过。最终种子的pedestrian-traffic十二分钟模拟通过，检查人车/车车和最后一分钟进展。

静音且禁存档浏览器实际走过入口扶梯、安检、闸机和B2扶梯，按目标进入车厢并完整抵达陆家嘴下车，记录security=1、metro=1。原第一次B2出口提示切换过早造成回到坡道，已修正并重复通过完整路径。任务栏“地图查看”实际打开地图并绘制黄色目标。有效验收数据在.local-data/qa/quest-crowd-browser-results.json、quest-map-v33.png。面部画廊展示实际头部纹理，背景照片仅为测试场景，不作为帧率或实际街景构图证据。
