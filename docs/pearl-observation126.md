# 东方明珠玻璃观景层与外滩立面 · 126

## 体验和参考

底层 V / 互动进入东方明珠上球体，观景层可环视两岸、在局部透明玻璃地面向下看。靠近电梯按 V 返回。小食柜台可免费领取一份糕点（背包食物，存档内每位玩家一次）；原“云端之光”移动到室内，已收集状态按原 id 保留。

游戏是压缩比例的方块世界，参考[上海市文旅推广网的 259 米透明观光环廊](https://www.meet-in-shanghai.net/cn/pudong-new-area/shanghai-oriental-pearl-radio-and-television-tower-248684/)和外滩[海关、汇丰与历史建筑资料](https://mzj.sh.gov.cn/lnb-wsws/20200518/MZ_LNB12_9104.html)，不宣称等比例复刻。外滩和平饭店强化竖向线条；汇丰、海关加强柱廊与入口石线，保持门洞与原屋顶/钟楼。

## 数据与实现

`pearl-observation-layout.js` 是纯地图/碰撞模块：生成球体内开口、保留核心支撑、清除旧外挑平台；共享电梯落点、柜台与晶体坐标。玻璃地板和外围防护碰撞有明确高度/半径边界；绝大多数地面碰撞先走数值范围快退。`pearl-observation.js` 只负责画面，参照上海中心使用半透明、双面、禁深度写入材质，地板/玻璃共用材质，静态小食/支柱和地面电梯框按材料合批，不新增实时灯或逐帧动画。原有烟花、人物和城市更新独立运行。

地图缓存更新为 v85：旧默认地图缓存会被重新生成；玩家建造、任务和存档不放入此缓存。Save v6 与 Map 11 接口保持。读取旧存档时，旧外挑平台上的非飞行玩家安全移到室内落点，其他位置与玩家编辑照常恢复；旧晶体和新糕点状态都沿用 adventure 存档，旧存档没有糕点字段时默认为未领取。地图快照继续由当前源生成并按内容哈希校验。

默认世界逐字节对比上一发布：176 格变化，全部在 x122..130、y68..72、z38..50；范围外0，地表数组不变。旧世界 SHA-256 `22b9d26d0b9806b35424081da33b22df925f64ea51dff88a11892c08b48a6128`，新版 `ad7784ec0b610516ef2be44389ec8954001cfae7b1caf5648753da710d63bb02`。`tests/road-clearance.test.mjs` 对 19840 个道路采样及地表哈希保留原断言；地图哈希仅在确认明确范围变化后更新，比较脚本 `.local-data/qa/compare-pearl126.mjs` 记录证据。
