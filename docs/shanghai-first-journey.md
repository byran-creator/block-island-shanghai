# 初到上海 · 一张明信片

这条主线把现有场景串成第一次来上海的完整旅程。没有新增大型场景、视频文件或远程语音依赖；现有建筑、贴图、人流、存档建造与交通模拟保留。

## 路线与完成条件

|章|体验|实际完成条件|
|---|---|---|
|1|外滩初见、林阿姨的明信片|走近林阿姨 V，读完对话|
|2|南京路选一份商品|真实柜台购买成功；随后店员介绍路线|
|3|2号线过江|南京东路→陆家嘴，实际发车、到站并下车|
|4|上海中心登高|使用上海中心电梯选择巅峰观景台；直接传送不计|
|5|返回熟悉的街口|陆家嘴→南京东路，实际完成2号线返程|
|6|付费区换乘、去豫园|南京东路→豫园，实际完成10号线旅程|
|7|园门里的慢时光|与顾先生对话，再实际检票穿过内园闸机|
|8|一扇窗里的风景|站在北侧圆窗内、望向窗外且视线无遮挡两秒，或完成三道灯谜|
|9|湖心亭坐一坐|沿现有曲径离园、九曲桥到亭，实际品茶|
|10|沈伯的纪念章|读完对话，选择江风/灯火/茶香，领取唯一纪念卡|

两次地铁线路及来回方向分别判定。2号线陆家嘴抵达后指向B2上行扶梯→B1出闸→3号口→上海中心；南京东路返程则指向付费换乘通道。豫园到达后先引导正常出闸上街面。园内和九曲桥目标沿已有曲径分段转弯，不以穿水或穿堂屋的直线作为路线。

## 节奏与界面

开场为现有外滩、南京路场景的20秒实机四分镜（江面远景→外滩历史街面→南京路→林阿姨）；终章为16秒三分镜（茶亭近景→园林中景→升高拉远）。Esc、空格或跳过按钮可随时结束短片。短片期间暂停角色/模拟、隐藏HUD，缓入缓出、部分弧形轨迹、轻微焦段变化和移动注视点，切镜时短暂淡黑，隐藏场景悬浮字；保存并恢复原镜头、视场角和标识可见性；系统减少动态效果时不移动镜头。沿用已有音乐与音量设置。

WASD/环顾/V/I/M/O新手提示随第一章显示；前两章完成后明确说明可自由探索。在I里进入“初到上海”，可以继续追踪、收起追踪或查看十章进度。现有13项城市支线及明珠支线保留，领取规则不变。主线不封锁建造、生存或旅行。

三位剧情NPC及购物后店员对话采用分页、可退出的原创文本。外滩、上海中心、跨江、园门、圆窗和喝茶有简短内心独白字幕，不抢角色控制，可收起；没有声称采用真人旁白。接取、章节完成、纪念奖励的短音符均为原创合成提示，不使用《原神》素材。静音/音量零/后台取消声音，播放节点结束后释放。

纪念卡随存档保存，只有一份。终章后显示十章结算与选择的纪念词；O背包点击纪念卡可重看，I可重播终章。结算只表示这条十章主线完成，不要求玩家清空城市支线。时长统计为主线活动模拟时间，不含菜单、短片与暂停，不作为性能或实际钟表时间基准。

## 工程与兼容

`shanghai-journey-state.js`独立管理顺序事件、自由追踪、唯一奖励与恢复；`shanghai-journey-targets.js`复用已有地铁/商店指导并补齐出站与园内路径；`shanghai-journey-content.js`集中管理剧情文案/镜头；`shanghai-journey.js`负责UI及小型NPC。统一recordCityEvent同时通知旧支线和新主线，不替换原事件语义。

新增存档字段journey，主存档版本6、地图修订11、基础缓存69保持。旧存档恢复后不自动传送、不强播开场，可从菜单或I自愿开启；个人建造/拆除照常恢复。中断开场恢复成可玩的第一章，中断终章恢复已完成，不重复发奖。剧情推进与现有编辑/存档流程分开。
