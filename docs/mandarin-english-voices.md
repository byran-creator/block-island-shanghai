# 普通话与英语播报

此前把所有 `zh` 语音列为中文候选，导致 `zh-HK` 粤语自然嗓音被自动选择，或被旧设置保留。现在按语言筛选，普通话限定 `zh-CN`、`zh-SG`、`zh-TW` 和 `cmn`，优先大陆普通话；排除粤语、港澳粤语标签与名称。旧保存的粤语嗓音无法覆盖此限制。

地铁默认先普通话、后英语，覆盖进站、到站、下一站、关门和体验终点提示。商贩默认普通话。设置内可以分别选择普通话、中英双语或英语，并记住选择。中文内容只交给普通话嗓音，英语使用对应英文内容与英语嗓音。双语字幕保留；浏览器缺少对应语言嗓音时跳过该语言的声音，不使用默认语音兜底。

配音仍使用浏览器提供的语音合成，不是实录。已有静音、后台暂停、对话停止吆喝的规则保留，不更改城市缓存和存档。

验证：`node tests/voice-languages.test.mjs` 与原生语音选择、地铁及商贩环境音回归测试。
