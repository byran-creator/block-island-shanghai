# 陆家嘴人流与任务导航

陆家嘴新增18位环境行人：8位携公文包的通勤人士、10位游客，其中6位会停下举相机。分布在中央绿地的既有步道、写字楼附近及金茂和环球金融中心附近铺装空地；不新增铺路或拆楼。复用NPC材质、独立步速与停留节奏、转向和人车避让逻辑，移动仅接受已有铺装、有落脚地面且无实体占用的位置。

这18人现在跟随游戏时钟生活：职员约08:15—08:51分批上班，白天错开咖啡与午休时间外出，17:30—18:06后步行回现有商住街坊；游客约09:00—09:48外出，22:15—23:03后回香格里拉。夜间仍保留晚归游客，其他地区的人流与任务人物不变。NPC对话里可询问接下来的安排。楼内活动以室内状态表示，不模拟办公桌和客房。

通勤沿有限范围的既有铺装寻路，整个人物脚印避开草坪与机动车道；每帧至多为一人规划路线，实际行走持续核对地面、障碍、人车和玩家。只在走到门后时隐藏，次日从同一门内出来；调时间不会让已出现的人跳到目的地。初次生成按当前时段放置在楼内或原有游览空地。路径不是存档内容，继续从已保存的游戏时间恢复日程，不改建造记录或存档格式。
