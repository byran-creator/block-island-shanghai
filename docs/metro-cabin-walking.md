# 地铁车内走动与选座

上车后用 WASD 走动，鼠标看向需要前进的方向；Shift 快走。八节车厢通过中间通道连接。靠近任意空座按 F 坐下，再按 F 起身换座。有人占用的座位不能使用。列车到站开门后，可直接走出车门或按 V 辅助下车。

此前乘车每帧把玩家固定在上车门的位置，F 也只是切换预设坐姿。现在保存相对于列车的车内位置，移动时检查车壁、座椅、扶手杆、乘客和连接通道；转弯时同步位置与视角。座位与乘客使用同一组48个位置，玩家所坐的位置保留给玩家，避免乘客重新显示时重叠。

关门后无法走出车厢；到达体验区的另一站后，关门前会自动安全下车。存档仍保存到安全站台位置，不保存行驶中的车厢坐标。地铁通勤任务仍需实际发车并到达另一站。

验收：绕过扶手杆、两处选座和换座、拒绝已占座位、跨车厢、车壁与地板安全、转弯随车、暂停、存档、通勤任务及不按 V 步行下车，通过 metro-cabin 回归。原有地铁基础、四入口进出站、设施、标识、声音和任务引导回归通过。静音且禁用存档的浏览器试玩确认上车、步行到座椅、坐下、换座和随车移动。
