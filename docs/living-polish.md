# 时间、天空和两岸室内细化

## 参考和结果

实际查看[和平饭店官方沙逊套房照片](https://www.fairmont.com/es/hotels/shanghai/fairmont-peace-hotel/rooms/SassoonSuite.room.html)，提取深色橡木护墙、奶油色格栅吊顶、紫灰色织物、床头灯、窗帘和地毯的配色关系。游戏使用自制几何软装，保留此前两套房的尺寸、传送点和江景窗；并非对实房面积、平面布局或品牌家具的严格复刻。

两处套房增加护墙线脚、灯槽、格栅吊顶、分缝木地板、图案地毯、褶皱窗帘、软包床头、床尾凳、阅读椅、沙发靠垫、茶具和花瓶、桌面书籍、装饰画、浴缸边框和镜面。静态构件继续合批；中央通道、出口、阳台和看江视线保留。

外卖车辆参考此前已查看的[文汇电动车实景](https://whb-oss.oss-cn-shanghai.aliyuncs.com/zhuzhan/cs/20190225/244350.html)，进一步区分踏板、封闭电池外壳、前挡板、座垫、后视镜和配送箱；骑手双脚位于踏板，普通骑车市民没有配送箱和外卖头盔。骑手数量每路6改5、相位和速度独立，并加入不同地点和时长的送餐停留。红灯或堵车时仍可能合理排队，不承诺任何时候都完全不并行。

月亮由带立体陨坑的大球改为小型朝向镜头的圆盘和低对比度斑点，固定远处距离、随观察位置平移。夜间提高天空仰角，降低透明度并随云雾衰减；采用简化满月而非完整月相或天文历表。

## 时间操作与兼容

右上角时钟打开暂停菜单的时间设置，支持精确到分钟的时刻、全天滑块、四个快捷时段、20/40/60/120分钟昼夜长度和固定时刻。旧存档没有设置时使用40分钟自然流动。新设置随存档保存，不修改存档修订号或基础城市缓存版本。固定时刻只冻结昼夜，交通和列车照常运行。

## 地铁上车修正

原逻辑每五个班次安排一次 `full`，同时拒绝互动上车和封闭物理门洞；表现为门已开却“挤不上车”。取消这一人为限制，保留拥挤乘客和无座提示；开门后步行进入自动乘车，V 为辅助方式。安检刷闸及关门期间的正常限制保留。

## 验证

- atmosphere：全天1440分钟的时刻转换、各昼夜长度、固定时间、旧设置回退、远处月亮距离/高仰角/透明度和跟随镜头。
- traffic-scene 与 traffic-media：所有外卖骑手为电动车，普通骑车者独立；模拟两分钟，车辆和骑手均移动且没有互相穿插。
- river-life：两套房中央通道、出口和江景视线支撑；浏览器实际步行到门口并返回大堂均通过。
- metro：无座拥挤班次也允许物理门洞通行并步行自动乘车，双向行驶和存档保留通过；浏览器以实际人物物理步行50步进入拥挤班次，`boarded=true`。
- 浏览器输入21:45、选择60分钟和固定时刻后，存档捕获的值一致；乘车后时间仍为21:45。套房、远处月亮、电动车和时间界面保存实际截图。
