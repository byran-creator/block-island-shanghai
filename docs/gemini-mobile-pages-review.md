# 手机端、Pages 与轻量夜景工程记录

审查基线：GitHub main d7ddde9d9084233524c7a95cd2a02742b62a8c86，继承 2adc046 后的 Gemini 手机端与 Pages 改动。保留触控方向键、横屏、时间滑块、可拖动任务入口、天空和道路防重叠调整。

## 存档与入口

- GitHub Pages 是静态分享入口，保存当前浏览器的最新进度；原 Sites 入口继续使用既有账号云存档。两个源的浏览器存储不共享，也不把凭据跨域发送。
- 导出、导入 JSON 用于跨入口或设备迁移。导入前保留一份本机备份，先验证格式、大小和坐标，再触碰游戏状态。浏览器存储写入失败会明确提示，不宣称已经落盘。
- 短暂网络错误不再永久锁死云存档；开发服务器返回 storage:local 仍使用磁盘接口。首进游戏会等有界的存档读取结束，不以 300/350ms 竞速启动新世界，也不会稍后突然覆盖玩家位置。无法确认旧云记录时，自动保存仅留本机草稿，直到用户读取旧记录或主动手动保存。

## 轻量画面

- 像素比上限恢复 1.25，保留抗锯齿与手机操作；相较 2.0 上限，避免在高分屏上扩大 2.56 倍像素绘制量。雾的远端与裁剪距离重新配合。
- 建筑名与玩法浮字使用透明纹理、淡金/青白文字和细暗描边，不修改真实地铁指示牌或店铺实体招牌。操作提示去掉底板。
- 南京路静态几何预计算窗光的近似漫反射，用每受影响顶点 1 字节的归一化强度（统一暖色） 加到夜间材质。保持原几何、贴图、AO、雾和实时角色照明；不增加点光源、纹理或绘制提交。白天该项为零。地形重建时同步烘焙，因此建造、挖掘和读档不会留下独立悬空光斑模型。共享或人物几何不烘焙。
- 这属于小范围近似照明，不是全场景物理光线追踪。启动/重建时计算，连续游玩帧不重算烘焙，只有昼夜切换更新颜色；仅缓存受影响顶点的原始颜色和强度，地形几何销毁时释放。

## 发布

Pages 的 main CI 运行定向回归，构建并归档带内容哈希的 JS bundle 与样式。正式站点保留原有 gh-pages 分支根目录发布方式，将经过验证的 dist/pages 内容同步到该分支；保留分支历史，并确认 GitHub 自动的 pages build and deployment 成功。原配置只允许 gh-pages 部署，不修改该保护规则，也不假设 main 的构建成功就代表网站已发布。更新不再只给主脚本手写日期、留下旧依赖缓存。Sites 继续采用已有 Worker、DB 和 BUCKET，不变更玩家存档版本、地图版本或数据库。

后续开发宜从最新 main 建分支，经检查后合并；一次审查不重写 Gemini 已经可用的移动端体验。

## 验证记录

合入 Gemini 后的基线 74 个测试脚本分别通过（本机磁盘存档测试需在正常 Windows 权限下执行）。修正了 Gemini 更新后两处陈旧测试：月亮半径与测试 DOM 的 querySelectorAll。此后追加行人与相机修改，发布前运行十项定向回归，并复测原55人街面、几何合批与车辆/行人碰撞。

本机 1280×720、像素比1 的静音禁存档短采样中，原始/烘焙模式两镜位的灯数、draw calls 和三角形数一致。先前独立着色步骤在部分视角增加 GPU 耗时，已弃用；最终方案复用顶点颜色，新增缓存约6.24MiB，不额外增加 GPU 属性。成组 GPU 查询存在系统波动，不据此宣称固定 FPS 提升。完整数据保留在本机 QA 记录。

## 本轮追加：行人与相机

- Gemini 的外滩往返游客在红灯区直接写入固定坐标、观景结束后直接回起点，且部分分支朝向反了。现在让他们真实步行返回，按位移转向，红灯只限制尚未越过等待线的下一步。排队、游览和普通街面游客互相保持身体间距；避让含转身和连续退让，不把人搬走。观景路线跟随实际岸线，回街节点分散，避免所有人挤一个点。
- 新增六分钟独立游客模拟与五分钟真实城市/信号灯/商店人群测试，末分钟每位游客仍有进展；原55人街面两分钟回归保持无碰撞、无瞬移与平滑转身。
- 摄影游客肩部旋转方向修正，手在身前托住相机。新增玩家相机：自拍/拍景、拖动构图、PNG 导出，进入时暂停，退出恢复原视角；仅保留一张预览并回收 Blob URL，关闭过程中完成的异步截图不产生泄漏，显卡上下文丢失会安全退出。拍摄立即渲染再读取画布，无需永久开启 preserveDrawingBuffer。
- 暂停菜单15Hz、拍照30Hz、后台停止场景绘制；正常游玩与剧情短片的刷新流程保留。此项减少闲置负载，不冒称提高所有游玩视角帧率。
- 本机真实场景短试玩覆盖南京路夜间旋转、外滩路口、豫园夜景与摄影游客；相机生成1280×720照片，切换、预览、导出入口和退出恢复均验证，控制台无错误。部分大视角帧时间仍偏高（约67–100ms的短采样中位数），不能承诺流畅或固定帧率。

发布检查发现原站为 gh-pages 分支模式，而 Gemini 留有 main 上直接部署 github-pages 环境的冲突工作流。本次将 main 工作流改为验证与归档（只读仓库权限），正式输出继续发布到既有 gh-pages 分支；不降低环境保护、不增加新凭据。
