# 新手路线箭头 · 2026-10-21

任务栏原等边三角形换成带长箭杆的金色SVG箭头，仍按原有镜头相对角度旋转。电脑、手机使用同一图案，避免三角形三个尖角使方向不明确。

开始菜单重复的“生存挑战”入口在电脑和手机均隐藏。原“切换创造 / 生存模式”和设置里的模式切换保留，原事件ID兼容旧工具，不新增模式或改动存档。

前三章原来的地面提示只能验证朝目标的一小段直线，遇墙或路面便全部消失。本轮改为有节点上限的A*路线，绕开建筑，使用现有斑马线和地铁坡道；后续只绘制玩家前方最多6个箭头。街上箭头约为之前1.8倍线性尺寸，扶梯和地下相应收窄并贴合坡度。共享几何和材质，仍无实时灯。

寻路每8个展开节点让出执行，游戏每帧只推进一段；目的地变更、偏离原路或遇到新增障碍才重新规划，失败有两秒冷却。每半秒重新检查可见前段的地面、墙体和已传入的闸机/家具碰撞；原路可用时不重复全程寻路。规划上限1800节点、240格，无法确认的路线不硬画穿墙箭头。

南京路两处过街沿现有斑马线规划，显示阶段读取同一交通周期和来车状态。允许通行时间不足10秒或车道未腾空时，箭头停在等待线前，任务栏提示稍候；已在斑马线中间则继续指向离开道路。方向箭头是引导，不改变红绿灯、车流或玩家控制。

原前两章后开放自由探索、前三章箭头可收起、任务进度/玩家建造/背包、拍照时隐藏引导均保留。小修补充到现有公告和手册，不新增独立版本通知。

验证包含真实世界从外滩到南京路的两处过街、绕墙路线、入口扶梯到B1、红灯等待及中途清空道路、后来新增障碍、分帧求解和复用网格；SVG与桌面入口显示另做真实界面验收。记录中的分帧耗时是本机测试，不代表手机帧率保证。
