# 地铁进出站分区修复 · v36

陆家嘴两个地面入口的扶梯原来落在闸机内侧，安检机却在外侧，导致返程旅客无法接近安检。闸机碰撞又错误地依据持票状态永久开放，出站可以绕过刷票；刷出站票后立即清掉权限，则会在闸机中间关门。

两站现采用相同的进出站流程：地面入口 → B1非付费站厅 → 背包安检 → V刷票、步行过闸 → 付费站厅 → 扶梯下B2站台。出站从B2上B1，先在闸机按V刷出站票、走过闸机，再沿原入口扶梯回地面。在付费区内到对面站台返程，无需再次安检；已经出闸的旅客，重新进站要再安检和刷票。

保留四个地面入口的街道位置、上下两层和既有扶梯。将北侧入口通道与西侧安检厅归为非付费区，用L形玻璃分隔与东南付费站厅隔开。模型、玩家和乘客共享分隔边界。B2扶梯只从付费区进入，未刷票不能直接走过去。

刷票后闸机开放4秒；真正跨过通道才完成进/出闸。未通过而超时会关闸，但可重新刷票。持票状态和闸机开放状态分开；重复按V不会撤销正在进行的通行，存档恢复也不会把闸机永久打开。站厅标识区分“出站检票”和入口通道，任务追踪在开闸后指向通道另一侧。站外站名牌改由下方两侧支柱支撑，文字不再被中间立柱遮住。

## 验收

- 新增 metro-flow 回归：两站四个入口均可走到安检，闭闸时无法绕行到B2；安检/开闸/步行穿闸/下B2/刷出站票/回到原入口/出闸后重新安检/开闸超时均通过。
- 既有地铁登车、双向跨江、存档和任务判定回归通过；68名乘客六分钟运行保持设备碰撞和活动范围正确。
