# 黄包车与豫园站入口净空

2026-10-16工程修复记录，不作为游戏中的独立版本公告。

原路线从豫园北侧直行经过局部坐标(-86,150)，与10号线北侧入口棚及扶梯开口相交。原避让仅检查行人和其他车，固定路线没有站口约束。

北侧巡游线改为在既有铺装广场北沿绕行，不移动地铁口、不拆建筑、不改站内布局。入口禁行区从两处真实10号线出口和入口棚共用布局计算，并包含扶梯开口与护栏。车体检查包含前方2.8米的车夫/车辕、后方1米的车厢和两侧0.9米范围；预测避让车道及最终平移/转向都检查，长帧细分检测，不能从入口另一侧跳过去。北侧转弯处缩小横向避让幅度，使整车留在现有铺装上。初始化时也直接放在合法巡游路线，避免首帧从原点跳过去。

回归先复现旧路线、车中心在外但车夫侵入、跨站口大步长等情况；随后8辆真实车运行12分钟变帧率，后半程加入避让干扰，检查两站口净空、巡游进展和变更拐角的车体地面支撑/方块碰撞，共6,445次拐角整车检查通过。保留乘坐、上下车、镜头、声音距离、车轮和人物动画，原合批姿态及存档测试另验。

玩家公告只保留豫园、商业街、园林、10号线等主要新增内容，删除独立V55/V53小修补公告与零碎修复条目。V54主要公告已读状态承接原V55已读状态，不因本次工程修复再弹窗。技术修复继续留在Git提交和工程记录中，存档和个人建造不变。
