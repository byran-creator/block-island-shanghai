# 南京路夜间立面照明

夜晚以现有石材贴图和自发光材质增强南京路的上层石墙及一楼石面；临街立面增加一层暖色透明照明，按照原有开口留出店门。白天关闭，原建筑、方块、碰撞与玩家存档保持不变。立面照明归外滩场景所有，构造时并入单个静态批次，无实时点光源、独立纹理或逐帧几何重建。新增透明绘制和局部填充存在成本，不能宣称完全零成本或代表手机帧率。

固定本机夜景镜位核对墙面与店门，并验证白天关闭、材质复用、一个合批、行人交通及原静态几何；本轮没有手机真机性能采样。

后续微调：立面暖光放在窗面之后，临街较低的拱窗按店招宽度向两侧避让；部分没有侧悬竖招的楼在门牌上方增加暖色竖向装饰，沿用静态夜景合批。店招、门洞与窗户的可见性需同时核对，不能只检查材质参数。
