河道、桥、道路、现有地标坐标不变；两栋新增地块仅占南岸现有空地，检查河道、道路、楼门净空。原版与候选完整默认体素逐格对比，931格有变化，范围 x=21..36、y=22..41、z=-12..0，原有楼宇未移除；地图缓存版本更新，以重建默认地图，个人编辑仍按原有方式恢复。建在新地块上的旧玩家建筑仍可能与新增环境发生空间重叠，不能仅凭保存数据完整来保证视觉或通行完全无冲突。

两栋建筑复用既有建模材质、纹理与静态合批；独立 Node 场景结构对照夜间可见网格 1683→1683、窗批 115→115。这不是实际镜头 draw calls 或手机帧率测试。同镜位本机画面检查河口及建筑尺度；实际流畅度仍需手机验证。
