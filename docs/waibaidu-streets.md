# 外白渡桥、车流与汤臣楼身

本次保留既有地标和个人存档，修复道路、标牌和汤臣一品楼身。地图仍采用压缩比例，地理关系按实景处理，不宣称测绘级坐标或完整复刻住宅小区。

## 实景依据

- [虹口区政府：外白渡桥](https://www.shhk.gov.cn/zjhk/001003/001003002/20140902/a423fff6-23fd-48a8-bf5d-ba5bf6a06a0e.html)：位于苏州河口西侧，连接南端中山东一路和北端大名路。游戏桥放在外滩北端，跨苏州河，不横跨黄浦江。
- [外白渡桥实景照片](https://commons.wikimedia.org/wiki/File:Waibaiduqiao_Bridge_on_Suzhouhe_River.JPG)：已实际查看双跨钢桁架、交叉腹杆、两侧步道和石质桥墩，据此制作原创简化模型，没有把照片作为游戏贴图。
- [汤臣集团：汤臣一品](https://www.tomson-group.com/product/20.html)：已查看官方楼群照片。楼身采用浅暖石色、连续窗带与住宅横向线条；本次建模一栋主楼承载既有高层套房，不声称完成四栋实物楼群复刻。

## 实施和根因

- 外白渡桥有水平实体桥面、双侧步道、双跨钢桁架、桥墩、栏杆和夜灯。北外滩道路经新桥连接；地图新增「外白渡桥 · 苏州河口」传送点。
- 普通车行道路半宽至少4格，双向车道偏移2.2格；闭合路线转角平滑处理。只移除新河道或拓宽道路占用的普通填充楼，保留固定历史建筑坐标。
- 旧车道过近建筑侧面，公交完整车身在转弯时受到阻挡；不同路线的共用汇入点又会互相顶住。拓宽道路、清理净空，给主要汇入点增加依次通行控制。新桥接回北外滩旧路的接缝对齐，避免急弯中的追尾互锁；可驾驶车辆的初始停车位置按完整车身移到道路外。旧骑手短循环在汽车车道中掉头，现在沿外滩街区绕行，保留独立速度、红灯、配送停留和真实车身碰撞。
- 南京路牌子原来用地面地块边界和小数楼层推算位置，无法跟随上层退台。现在按实际整数楼层的墙面计算位置，竖排字逐层贴墙，字牌高度避开退台交界。
- 汤臣地块后续定义曾覆盖原高楼高度，套房仍在77格高，因而浮在短楼上方。最后有效定义改为连续60格住宅楼身，实体外墙和楼板从地面延伸至原套房以上，江景面在房间层留出无遮挡窗口。套房与传送位置保持。

## 验证

- `harbour-streets` 检查桥梁与苏州河、黄浦江、外滩的方位，实体桥面与两侧步道、汤臣连续支撑、所有南京路店铺的贴墙位置、全部汽车路线两条车道的完整车身净空和汇入点放行。
- `traffic-scene` 连续运行9分钟：前6分钟验证所有车身不重叠，最后1分钟每名交通主体仍有位移；再加路边停放障碍运行3分钟，验证不穿车、不瞬移及最后1分钟全车流仍有进展。保留真实红灯和公交停站造成的短暂排队。
- 独立本地浏览器试玩关闭声音和存档写入，验证步行过桥、套房支撑与江景、贴墙霓虹，并运行包含路边车辆和NPC的6分钟交通检查。

基础城市缓存随地图更新重建一次；之后继续复用缓存，个人存档不清除。玩家自行放置在道路上的方块仍可能影响通行。
