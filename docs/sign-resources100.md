# 街招复用与地下屏幕更新

日期：2026-10-24，基线 main `3f5d547`。落实99轮核对后的第一批资源优化；不改分辨率、抗锯齿、视距、灯光、内容人数、交通与存档格式（Save6 / Map11 / Cache84）。未连接手机，不能把本机诊断换算为手机FPS，或声称排除了iPhone快速转向时的网页自动重载。

## 修改与资源归属

- 换乘通道是后建的独立根节点，原来没有加入地铁地下可见性归属；后添加的转向牌也错过了首次分类。现在独立通道采用原45米入口/地下判定，`addSign`登记低于地表的构件，街面入口保留。玩家编辑、拍照和剧情运镜保守豁免；显式坐标查询与恢复首帧矩阵刷新沿用原契约。
- 到站屏与车厢路线屏的时刻/逻辑内容照常推进，只延后隐藏祖先下的画布绘制。待显示内容只有最新一份，不缓存历史倒计时；恢复可见的同帧刷新，即使尚未跨过下一秒。公开`paint`仍立即执行，私有动态画布及静态牌首次重绘分离规则保留。列车、乘客、扶梯、门闸、声音和任务模拟没有暂停。
- `street-sign-art.js`复用完整绘制参数相同的不可变日/夜画布与材质，物理宽高相同的平面共享几何。保留原尺寸、字体、原绘制函数、UV、颜色空间、mip和各向异性。昼夜材质仅在状态变化时赋值；不是通过减少招牌或修改颜色节约资源。
- `npc-name-art.js`按原固定绘制样式和称号共享纹理，保持原采样参数。每个人仍有独立的Sprite及SpriteMaterial，名称牌可见性、透明度和NPC交互互不影响。

两个资源池分别属于一次`createCityActivity`和`createNpcGuides`实例，无跨场景全局缓存，目前与整个常驻城市场景同寿命。池的`dispose`释放每个唯一纹理/材质/几何一次，调用方须先移除全部使用者；现有游戏没有片区卸载入口，不增加伪装成完整卸载的局部`dispose`。未来引入卸载时，须接通场景所有者释放唯一资源集合、丢弃旧模块及池的流程，不能只移除一个共享使用者就释放贴图，也不能保留旧模块闭包作为全局缓存。

## 验证范围

新增回归覆盖完整绘制操作/尺寸/几何字节、不同参数隔离、单场景归属、释放一次、NPC独立材质、真实街区连续昼夜切换与不变状态零材质写入；地下测试覆盖后增构件归属、隐藏不重绘但时刻继续、同秒首帧恢复、公开重绘接口、街面与编辑豁免。原标牌、双面方向、换乘出站、矩阵与对话回归继续保留。

本地54项`npm run test:release`通过；新增两项已同时接入完整测试链和发布链。功能回归不是手机性能门禁，没有通过放宽基线处理失败。

本地完整渲染对照固定同浏览器、1055×487实际画布、MSAA、seed100、相同时间天气和镜位，使用最小化打包的专用页，静音且禁玩家存档/偏好写入。运行采样100帧排前20帧，统计帧函数内同步工作，包含绘制提交和可能的驱动等待，不是显示帧间隔或独立GPU计时。
