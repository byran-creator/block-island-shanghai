# 列车错时与双面方向

2026-10-11：原60秒循环、12秒停站、16秒行驶使对向列车在同站仅错开2秒。保持60秒候车循环与12秒停站，把区间行驶改为13秒，两站均错开5秒到站，不靠只改一列车偏移而让另一站时差错误。

方向牌原先正反面共用同一张图，背面仍画相同左右箭头。现按观看面反转左右箭头（上下箭头不变），同一块站台牌的目的地仍对应实际轨道。车内两侧的线路站序和箭头按观看面排列；每列车仅共享两张方向纹理，更新下一站时同步更新，未为每个门口独立分配贴图。绿色仍是可乘坐体验区间，灰色站尚未开放。

回归检验两站到站时间、四块站台牌正反箭头在世界空间中指向同一行车方向、32块车内牌的站序与箭头、动态下一站更新；保留行走/选座、安检/出闸和补砖修复。
