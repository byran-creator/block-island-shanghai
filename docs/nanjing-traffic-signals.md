# 南京路石碑路口信号修复

石碑前灯柱位于后侧南北道路，但原来属于外滩侧 `bund-66` 控制点；车辆路线只在外滩侧登记信号，因此后侧道路车辆不受眼前红灯约束。

现在为后侧道路建立 `stele-66` 控制点，灯柱和所有经过此处的汽车、公交、骑手使用同一个信号对象。保留原有两根灯柱及同步相位，没有重复增加灯柱或改变行人活动逻辑。车辆红灯、黄灯在停止线前等待；已越过停止线的车辆继续清空路口。

现有 `ROADS` 的半宽均至少为 4，汽车双向车道偏移为 ±2.2。这是每个方向一条车道，中央一条虚线不代表单车道；南京路主体保留步行用途。本轮没有再扩大道路、改建筑或修改城市缓存。

验证：`nanjing-signals.test.mjs` 检查真实路口登记、汽车/公交/骑手/南浦桥返程路线、双向不同车身长度的红黄灯停车，以及实际运行中车辆与可见灯色同步等待和放行。`harbour-streets.test.mjs` 检查所有车辆路线两侧完整车身净空；其他针对性回归及构建结果见本次交付记录。没有进行 GPU 试玩，不声称解决此前南浦大桥偶发排队停滞。
