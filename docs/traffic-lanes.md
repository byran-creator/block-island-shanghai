# 陆家嘴车流与分道修复

这批修复处理陆家嘴核心道路上汽车、公交和骑手长期互相卡住的问题。

## 根因与改动

- 骑手初始化时曾优先选择道路中心，即使路缘车道有完整车身净空。现在自行车和配送电动踏板车固定从路缘车道出发，并增加绿色车道和白色分隔线。机动车保持原来的双向车道。
- 原来的跟车逻辑只识别同一条路线里的车辆；不同路线的汽车和公交汇入同一车道后，没有提前保持车距。现在同时检查实际方向、车道和前方车身，安全间距随车速增加。
- 陆家嘴北侧两个汇入点缺少通行控制，相邻路口各自保留通行权也可能互相等待。补齐汇入点，并协调重叠区域的车辆通行；汽车、公交及骑手都参与相互冲突的转向让行，能安全并行的方向保持通行。绕行时按实际绕行路径检查。
- 路缘车道经过急弯时，实际行驶弧长比道路中心线长。骑手按实际位移限速，避免突然跳过一段弯道。
- 通行权不会把已经在前面的排队车辆锁住。罕见的两车互相顶住时，一方会低速直线倒退让行，并连续回到原路线；倒退、返回都检查整车碰撞，不用瞬移脱困。
- 南浦大桥东端的去、回路线共用弯道，相向转弯不能使用一般路口的并行放行规则。这里保留整段弯道的独占通行权，驶离后再交给等待车辆，避免堵塞蔓延到陆家嘴外围。

红灯、公交停站和避让行人仍会产生短暂停车。骑手遇到障碍时会检查碰撞后绕行，再回到原车道。这是游戏尺度下的交通模拟，并非真实交通流的完整复制。

## 验证与存档

五组针对性检查通过：整车净空、独立车道、跨路线跟车、相邻路口放行、持续车流、停车障碍绕行及行人安全。城市车流连续模拟15分钟，其中3分钟加入路缘停车障碍，车辆之间没有车身重叠，最后一分钟所有交通参与者仍有行驶进度。停车障碍测试中的骑手行驶222.54米，持续绕行后回到车道；骑手急弯和机动车倒退让行均检查连续位移。

另外，包含游客、商贩、居民、交警和散步行人的12分钟模拟检查793791次人物位置，没有行人和车辆重叠，最后一分钟车辆最少行驶20.41米。具体运行证据保存在本地检查点中。

实际浏览器独立静音模拟12分钟，检查784507次人物位置，碰撞为零，末分钟停滞车辆列表为空。第一轮浏览器测试曾发现桥头堵塞，修复后完整重测通过。

本批没有改变城市体素、地形缓存版本或玩家存档格式；绿色车道是显示模型。公开试玩地址保持不变。
