基线为 main `f50e554`。本轮保留手机默认1.25倍率、MSAA、30帧目标，清晰档1.5/60帧，保留材质、贴图、几何、视距、人物数量及交通时钟；不以降清晰度或删人物换取结果。主存档6、地图11、基础地图缓存84不变。

## 已定位和处理

- 首次无缓存的基础城市生成原来占用主线程。现在在模块Worker执行原生成器，直接转移56,070,144字节的体素及表面数组，随后终止Worker；旧WebView或禁用Worker时回退到原生成器。缓存命中不启动Worker。Sites与Pages均输出独立内容哈希的小Worker bundle，避免在后台再次请求一串源码模块。
- 读档原来强制同步重建所需的整片地形，即使没有任何建造变化。现在比较前后编辑记录，只作废真正变化的区块及相邻面；其余网格直接复用。当前位置先补近处，其余走原有限时队列。删除旧编辑也会重建，不会保留旧建筑残影。
- 多个区域仍提交被实体地面遮住的地铁内部。仅将最高点低于24的站内对象归组；远离所有站口45格、脚位不低于25且玩家未修改地形时才省去绘制。入口及上部扶梯始终保留，靠近入口、进入地下/换乘或玩家有建造记录时恢复。模拟、车门、班次、乘客、碰撞及存档照常运行。
- 地形面检查对真实VoxelWorld使用安全的直接索引，边界和被覆盖的自定义get仍保留原路径。分帧、编辑取消、单帧至多一次网格上传保持。
- 实例合批每帧复用祖先可见性结果，隐藏的原对象不再重复校验完整变换；重新显示、拆除、镜像、材质替换仍使用原回退规则。
- 首次夜景的驱动准备存在独立停顿：常见日/夜着色器在支持并行编译的设备上按小批次预热，进入游玩、动画和后台时暂停发起新批次。只使用临时代理对象，编译用的零强度灯同步移除，不改变正式场景。旧WebView不支持时保持原路径。
- 已链接成功的着色器原来仍读取三份驱动日志，实测单次可阻塞数百毫秒。游戏跳过健康程序的警告日志回读，链接状态仍检查，失败仍保留原错误日志与回调；工具默认诊断行为不变。驱动返回空日志时也不再触发空值异常。

## 可复核证据及限制

真实Node Worker与原生成器的整图SHA-256相同：体素 `22b9d26d0b9806b35424081da33b22df925f64ea51dff88a11892c08b48a6128`，表面 `995465d1bbe3c03b6c5bd6d01ad3a636d8076dfe0b0c155bbf6304347d72b88a`。等待Worker时主线程定时心跳持续执行。不可用时回退同一地图，保留缓存与玩家编辑的分离。

四区共100个区块、同一世界、串行交替3轮：原实现395.20/362.78/350.62ms，本轮298.64/274.71/229.25ms，中位约减少24.3%。所有位置、法线、UV、颜色与索引SHA相同 `5d8aa49089f66ad63ba9ca41b04cb2a23052873477937254613045eb1aa82a89`，193,592面完全一致。另有10个发布版GPU字节基准覆盖边界、空块和32位索引。此为Node网格工作负载，不是手机FPS。

桌面WebGL以844×390、实际画布1055×487、抗锯齿开启对照外滩同一镜位：恢复全部地下绘制1468次，省去被遮住部分934次，RGBA通道差异为0。此证据只覆盖该固定镜位，不泛称全部区域都逐像素验收。正常分批加载的外滩、南京路、陆家嘴、豫园短采样完成且无控制台异常；转入新视角和夜景仍有首次驱动使用的高峰，不能承诺所有手机30/60帧或冷启动等待已经明显缩短。

连续强制重建六个区域的早期压力页触发了驱动shader异常，该样本作废，不作为性能收益或通过证据；已停止并改用正常加载队列。尺寸/DPR不一致的早期样本同样剔除。保留原始QA记录，不据此声称真实微信或手机浏览器已验收。

首个夜景的驱动定向短采样：基线三次绘制约978/273/790ms，健康程序日志读取最慢653ms；只预编译仍有最慢365ms的日志等待。最终候选为148/46/56ms，程序数量89→89，无健康日志回读长等待或控制台错误。最终同镜位再次对照为1379→845次绘制，像素通道差异0，画布1055×487/MSAA不变。以上均为本机短样本，会受驱动、缓存和其他负载影响，不换算真实手机帧率或宣称整段游戏同比提升。

## 真机对比入口

在原试玩网址后添加 `?perf=1` 即可打开本机性能记录。普通网址无额外面板；不会上传数据或改变画质。记录最近300帧的帧间隔、帧内耗时（含绘制提交/驱动等待，并非独立GPU计时）、超过100ms的帧数、画布、抗锯齿、绘制提交及启动时间。可重新采样、复制报告；微信不支持剪贴板API时提供可长按复制的文本。暂停/切后台不计作卡顿。
