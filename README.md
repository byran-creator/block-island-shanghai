## 本地启动

建议安装 Node.js 24 LTS，然后在解压后的项目目录打开终端：

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

打开终端显示的本地地址（通常是 http://127.0.0.1:5173）。修改 `game/` 内文件后，浏览器会刷新；如果刷新，先保存进度。

本地启动包含存档接口，不需要登录云端账号。自动存档保留最新一条，手动保留最近十条，文件存放在 `.local-data/saves.json`。重启开发服务器后仍可读取。这个目录不加入 Git；换电脑时单独备份。浏览器待保存进度仍由浏览器的 localStorage 暂存。

**本地存档与线上存档彼此独立，不会自动下载、上传或同步。** 源码包不包含线上玩家存档。线上服务使用账号认证、数据库和对象存储；本地开发使用磁盘文件。

## 推荐开发方式

地图现在支持传送：按 **M** 点击青色景点圆点或景点名称。**Shift** 跑步，**CapsLock** 切换持续跑步。靠近可骑自行车、停放汽车、停站公交或白玉兰直升机按 **V** 搭乘；W/S 前后、A/D 转向，直升机空格上升、Shift 下降，V 在安全位置离开。**K** 播放无人机、烟花与陆家嘴交错聚光灯。东方明珠双球、平台及霓虹圈已收窄。详细位置与存档行为见 `docs/commuting-and-light-show.md`。

自行车和汽车采用渐进油门：**W** 加速、松开滑行，**S** 先刹车再倒车，**空格** 急刹，**1 / 2 / 3** 切换慢速／巡航／快速。低速转向更灵活；前轮、车把随方向转动，车轮随行进滚动，自行车转弯时轻微倾斜，跟随镜头平滑转向。碰到建筑会减速反弹并抖动；碰到行人会急刹，人物短暂踉跄；碰到其他车辆会反馈冲击，交通车辆保持行驶，玩家车辆承受减速反馈。这是轻量驾驶反馈，尚未实现完整刚体、车辆损坏或事故系统。

交警、美食／纪念品商贩和外卖小哥头顶有身份标签。步行靠近按 **V** 对话：交警指引最近的停车点、公交与路口通行，商贩提供游览建议并可进入原来的购买界面，外卖小哥介绍骑行操作。**Esc** 或“结束对话”返回游戏。

本地灯光秀改为三处江面发射点的 42 秒编排：金色开场、冰蓝星海、玫红花雨、金柳谢幕，包含低空扇形、高空花球、环形和垂柳拖尾。陆家嘴楼群灯带、地标 LED 和广告屏使用同一配色时间轴；18 处聚光灯以扇形扫动并交错闪亮。暂停菜单可直达步道空档的观赏点，**K** 重播。实景依据及验证见 `docs/harbour-show-and-bridge.md`。

南浦风格桥清出建筑净空，连续坡面与步行、驾驶、自动车流共用高度，增加 12 辆过桥车辆。桥梁仍采用游戏比例简化。碰车后可以沿脱离重叠的方向退开；自行车低速倒车不再被停稳阈值清零。直升机落地后按 **V** 在有支撑且避开机身的位置下机，恢复步行视角；近墙时驾驶镜头改用无遮挡的上方位置。NPC 对话显示在屏幕底部，保留场景与人物，回答选项在右侧。

本地修订 11 按补充地图将三件套及配套裙房向内陆后退 20 格，上海中心距东岸由约 11 格增加到约 31 格，保留它在金茂南侧、环球西南侧的关系。电梯、观景台、LED、小地图与旧存档的相关位置同步迁移。更新前备份在 `.local-data/backups/saves-before-revision11.json`。

本地街景细节更新：新增蓝白公交和站牌、外围道路的自行车与外卖电动车、南京路内步行送餐员、部分路口的三色信号灯／倒计时和交警。公交停站，机动车等待红黄灯并在绿灯后继续。上海中心增加曲面塔冠 LED 屏与螺旋灯带，金茂裙楼东侧增加横向广告屏；原创画面定时轮换，深夜关闭。实景依据及未执行项目见 `docs/street-detail-references.md`。公交停站时现在可以搭乘。

本地开发和试玩，使用 Git 保存版本，再将确定的版本发布到线上。鼠标操作、浏览器性能分析和视角调整在本地更方便；云端便于分享、继续长任务和发布。避免两边同时改同一份代码，先提交再同步。

菜单新增‘北外滩观景点’，可直接核对北侧天际线。晴天提高远景可见度，江雾和雨天仍保留雾效。

本地交通与区域声音更新：汽车、公交和骑手按实际车身范围互相避让，骑手使用有净空的路边车道；出生间距、车速和转弯减速各有差异，保留真实的红灯排队与公交停站。步行玩家碰到来车会被推向最近的安全空档，生存模式扣除生命，创造模式保留无敌与碰撞提示；自动交通不会因玩家靠近或碰触暂停。

暂停菜单新增“区域配乐”和“环境音”。南京路／店铺、龙凤厅、水下、生活岛与日夜城市自动匹配原创曲目，跨区域停留 1.2 秒后切换；手选曲目后关闭自动切换，可重新开启。环境音包含随距离和方位变化的车声、江水／雨声、步行脚步、进店铃、餐具轻响、停站公交提示与碰撞短鸣。近摊位的商贩间歇吆喝采用浏览器本地中文语音，没有可用语音时跳过；声音为程序合成，并非实地录音。静音、暂停或隐藏页面会停止环境声音和吆喝。详细验证见 `docs/traffic-and-scene-audio.md`。

## 地铁2号线与城市缓存

新增南京东路、陆家嘴两站，各有两个方向出入口。按 M 点击带“2号线”的站点到入口，沿自动扶梯下到B1，靠近安检机按 V 放包检查，再到绿色箭头闸机按 V 刷免费体验票，继续下扶梯到B2候车。车门打开后直接走进去自动上车，V 作为辅助上车操作；F 坐下/起身，V 到站下车。座位满时站立乘车，不再设置“挤不上车”的班次。返回对面站台可乘车回去。车站工作人员有底部对话引导。

## 时间、月亮和套房细化

点击画面右上角时钟，或在 Esc 暂停菜单中调整一天时间：输入具体时刻、拖动滑块或选择清晨/正午/傍晚/夜晚。一昼夜可选20、40、60、120分钟，也可固定当前时刻；设置随个人存档保留，旧存档默认40分钟自然流动。
