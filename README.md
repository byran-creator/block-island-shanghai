# 方块小岛 · 我的上海

一个持续开发中的第一人称方块沙盒原型：探索上海外滩、陆家嘴与黄浦江两岸，坐地铁、乘轮渡、逛店铺，也能回江景套房休息或在生活岛建造。

**[点击这里，直接浏览器试玩](https://wenqiang-block-island.byran172.chatgpt.site/)**

普通玩家不需要 clone、安装 Node.js 或下载客户端。电脑鼠标键盘体验更佳。这是单人游戏，各自拥有自己的世界；目前没有多人联机。

## 创作方式

作者：[@byran-creator](https://github.com/byran-creator)。

作者负责玩法设想、场景参考、体验判断及持续试玩反馈，使用自然语言与 AI 编程助手协作实现和迭代。这是学习与创作中的实验项目，采用压缩的游戏地理比例，仍欢迎指出问题和提出建议。

## 可以体验什么

- 外滩与陆家嘴天际线、南京路店铺和夜间灯光秀。
- 两站2号线地铁、轮渡、自行车、汽车、公交与直升机。
- 店铺实物商品与库存变化、和平饭店江景餐点。
- 两岸套房、浴缸放水和电视互动。
- NPC引导、城市任务、传送地图、天气与时间设置。
- 生活岛生存建造、潜水与跑酷。

## 怎么玩

WASD 移动，鼠标环顾；Shift 跑步，CapsLock 持续跑步。V 场景互动，M 地图与传送，I 城市任务，Esc 暂停。其余操作在游戏菜单中说明。

云端存档需要登录；访客待保存进度仅留在当前浏览器。刷新前建议手动保存。

## 本地开发

需要 Node.js 24 与 npm：

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

打开终端显示的本地地址，通常为 http://127.0.0.1:5173 。本地存档写入 .local-data/saves.json，与线上存档独立。

```sh
npm test
npm run build
```

本项目的生产服务使用 Worker、数据库及对象存储；GitHub 仓库用于展示与协作，试玩仍使用上面的现有网址。上传源码不会自动提供托管服务。当前构建不能原样部署到纯静态 GitHub Pages 并保留云端存档。

## 项目结构

游戏与场景代码位于 game/，本地开发服务位于 scripts/，生产存档服务位于 worker/，回归验证位于 tests/。docs/ 记录场景参考和实现限制。

## 最新地铁细节修复

安检设备与乘客共用碰撞边界，站内吊牌采用高位黑底中英导向，演唱会灯箱保留完整竖版海报。列车到站前加入真实轰隆声；安检员仍使用浏览器普通话/英语语音。夜影扩大身体碰撞检查。根因、实景参考与验收见 [本批说明](docs/metro-detail-update.md)。

离站后增加牵引电机与滚动声，逐渐远去；标识按实景和玩家参考图调整为分区吊牌、白底站名牌和每扇车门上方的中英线路条，显示双向行驶与下一站。声音来源、地理示意范围与验证见 [离站音效和标识更新](docs/metro-signs-departure.md)。


两站入口先到B1非付费站厅，安检后刷闸下B2；出站先在B1按V刷出站票再走向出口。出闸后重新进站需再安检，站内返程无需重复安检。陆家嘴入口牌立柱遮字及返程安检死锁已修复，四入口完整步行和重新进站返程验收见 [进出站分区修复](docs/metro-entry-exit.md)。


四个地铁口新增雨棚门头，站牌贴合门头，不再跨进店铺墙体。站台显示真实下一站方向；陆家嘴往东为浦东南路（原东昌路），之后是世纪大道。海关大钟按实景重绘四面罗马数字钟盘，指针对应游戏时间。南京路两组55名行人共用避让，保留购物袋间距、独立配速和停留，详见 [本批根因与验收](docs/station-canopies-clock-crowd.md)。


南京路行人增加稳定的绕行方向、平滑转身和步态启停，减少反复小步挪动。创造模式关闭并清除夜影；生存模式最多2只、每30秒补充，受保护区域安全，补齐转身后的头部碰撞范围。动作连续性与夜间模式验证见 [行人与夜影修复](docs/crowd-night-safety.md)。


南浦桥陆家嘴侧坡道修正横向倾斜，车辆按车头方向俯仰，桥面显示与既有物理高度对齐。上海中心塔冠广告改为正向竖排大字，修复接缝/镜像/遮挡并延长到午夜，详见 [桥面与广告验收](docs/bridge-crown-readability.md)。
